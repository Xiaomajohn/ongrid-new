## 典型操作命令

> Windows PowerShell 下用分号 `;` 分隔，例：
> `ssh root@192.168.25.30 "cd /opt/ongrid; ./ongrid --version"`

### 登录

```bash
# 服务端 / 打包机
ssh root@192.168.25.30
# 密码: 111111

# Edge 端
ssh root@192.168.25.56
# 密码: 111111
```

### 同步源码到打包机

```bash
# 在本地开发机执行
scp -r ./ongrid-new root@192.168.25.30:/opt/remotework/
```

### 服务端构建 & 安装（打包机上）

```bash
ssh root@192.168.25.30
cd /opt/remotework/ongrid-new
make package                       # 产物在 dist/
# 或直接构建二进制
make build-arm64                   # arm64 单架构（参考 .record 历史）
```

### Edge 端安装 / 更新

两种方式（在管理后台 `Edges` 页 → 行操作 → 「安装」弹窗里都有入口）：

1. **手动安装**：复制 curl 一行命令，在 192.168.25.56 上跑，产物落到
   `/mnt/data/tools-temp`。
2. **一键安装**：服务端复用设备表里的 SSH 凭据直连 192.168.25.56 执行
   install command，无需人工登录。

### 校验连通性

```bash
# 从服务端 ping / SSH 测 edge
ping 192.168.25.56
ssh root@192.168.25.56 "ls /mnt/data/tools-temp"
```
