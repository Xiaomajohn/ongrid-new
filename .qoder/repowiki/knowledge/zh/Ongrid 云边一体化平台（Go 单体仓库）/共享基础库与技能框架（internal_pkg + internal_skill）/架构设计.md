本模块由两个并列子域组成，均被上层 cmd/ongrid 和 cmd/ongrid-edge 共同依赖：

- internal/pkg：按横切关注点拆分的 Go 包集合，每个包聚焦单一职责且无内部层叠——auth（JWT 签发/校验 + HTTP Bearer 中间件写入 tenantctx）、authzmw（基于权限类的路由级鉴权中间件）、config（纯 os.Getenv 加载，零外部依赖，结构体字段即环境变量键名）、dbx（GORM AutoMigrate 编排入口 + 软删除 mixin）、llm（对 go-openai 的薄封装，内置每日 token 预算回调与 Prom 指标）、tunnel（geminio 重试端点的 JSON-RPC 包装，含指数退避拨号与 broker 路由失效自动重连）、notify/prom/promquery/promwrite/grafana/logquery/tracequery/qdrantx/mcpclient/zhipuauth 等均为对外部系统的单向 HTTP/gRPC 客户端；passwd/secretbox/runner/tenantctx/tracing/logger/errs/httpserver/embedding/docextract/workspace 提供密码学、上下文、进程运行、可观测性基础设施。

- internal/skill：L2 设备能力框架。types.go 定义 Executor/Metadata/Class/Scope/ParamSchema 等核心接口与元数据模型；registry.go 维护全局 RWMutex 保护的 skill 目录（init 时 Register，运行时 All/AllByClass/Get）；loader.go 扫描磁盘 skill.json 清单并构建 SubprocessSkill（通过标准输入输出与外部二进制通信，严格限制 entry 路径在 allowlist 根下，禁止逃逸）；builtin/ 内嵌一组 ScopeManager 的本地能力（web_search、tail_file、read_journal、probe_http/tcp/dns、host_netns_inspect、restart_service）。权限类 safe/mutating/dangerous 仅做标记，实际审批策略由 manager 侧服务层实现。

依赖方向：pkg → 外部系统；skill/builtin → pkg（如 config、logger、prom、notify、tunnel），但 pkg 不反向依赖 skill，保证两者均可被 manager 与 edge 独立引用。
