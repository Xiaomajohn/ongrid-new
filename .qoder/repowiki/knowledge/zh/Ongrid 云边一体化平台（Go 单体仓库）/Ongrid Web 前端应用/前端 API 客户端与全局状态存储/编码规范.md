- API 层每个资源一个文件，函数签名固定为 `return request<T>(METHOD, '/path', body?)`，并通过顶部注释列出后端路由以便对照。
- 所有响应体与入参都显式声明 TypeScript 类型（如 `LoginResponse`、`Me`、`CreateUserBody`），避免在调用处写 `any`。
- 需要鉴权的接口直接调用 `request`，无需鉴权（登录/刷新）的接口传入 `{ noAuth: true }` 阻止自动附加 Authorization。
- Zustand store 一律通过 `create<State>()(persist(..., { name: 'ongrid.<slice>', storage: createJSONStorage(() => localStorage) }))` 初始化，并以独立导出函数暴露 getter（如 `getToken`、`getRefreshToken`）。
