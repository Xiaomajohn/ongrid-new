- `web/src/api/client.ts` 是模块核心：导出 `request<T>(method, path, body, opts)` 统一构造 URL（拼接 BASE `/api/v1`）、注入 `Authorization: Bearer`、`Accept-Language`、JSON/FormData 编码，并在非 2xx 时抛出带 `status/code/payload` 的 `ApiError`。
- 内置 token 刷新：收到 401 且未设置 `noAuth` 时调用内部 `refreshAccessToken()`，通过 `/auth/refresh` 用 refresh_token 换取新 session，并用 `refreshInFlight` Promise 去重防止并发刷新；刷新失败则调用 `useAuth.getState().logout()` 强制登出。
- 每个后端资源对应一个同名文件（如 `users.ts`、`auth.ts`），仅依赖 `./client` 的 `request`，按 RESTful 路径组织函数，并声明对应的 TypeScript 类型（`LoginResponse`、`Me`、`User` 等）。
- `web/src/store/` 下每个文件是一个独立的 Zustand slice，使用 `zustand/middleware` 的 `persist` + `createJSONStorage(() => localStorage)` 将状态落盘，key 以 `ongrid.*` 命名空间隔离（如 `ongrid.auth`、`ongrid.theme`）；store 之间无相互依赖，由上层组件组合订阅。
