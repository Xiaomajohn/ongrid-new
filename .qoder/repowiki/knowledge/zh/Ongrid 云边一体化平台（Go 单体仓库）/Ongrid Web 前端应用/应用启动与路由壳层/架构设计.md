模块由三个职责清晰的文件组成：
- `main.tsx` 是 Vite 构建产物挂载点，在首次绘制前同步调用 `applyThemeOnBoot` / `applyAccentOnBoot` / `getLocale()` 把持久化主题、强调色和语言写入 DOM，再以 `<StrictMode><BrowserRouter><App /></BrowserRouter></StrictMode>` 形式挂载 React 18 root。
- `App.tsx` 是唯一的顶层路由定义处，使用 `react-router-dom` v6 的嵌套 `<Routes>/<Route>` 树；所有页面组件通过 `React.lazy(() => import(...))` 按路由拆分，配合 `<RequireAuth>` / `<PublicOnly>` 两个高阶组件统一做 token 校验与 `/login` 重定向；大量旧路径以 `<Navigate to=... replace/>` 做单向迁移（如 `/edges→/devices`、`/services→/topology`、`/settings/*→/admin/*`），体现“只增不删”的路由演进策略。
- `lib/routes.ts` 是与运行时路由解耦的**静态路由清单**，供命令面板（⌘P）等不需要 Sidebar 依赖的地方消费；每条定义包含中英双语 label、拼音/同义词 keywords 与分组 group，label 通过 `trInline` 延迟求值以响应 locale 切换；内置手写子序列匹配算法 `fuzzyMatchScore` + `scoreRoute`，避免引入 fuse.js 等外部搜索库。

依赖方向：`main.tsx → App.tsx → pages/*`（懒加载），`lib/routes.ts` 仅依赖 i18n 工具，不被 App 反向引用，形成“声明式路由 ↔ 静态目录”的双源结构。
