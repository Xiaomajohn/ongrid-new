- 页面组件一律通过 `React.lazy(() => import('@/pages/...'))` 按需加载，禁止在 App.tsx 顶部直接 import 页面。
- 受保护路由统一包裹 `<RequireAuth>`，公开路由包裹 `<PublicOnly>`，两者内部基于 `useAuth((s) => s.token)` 做跳转而非 props 透传。
- 废弃路由以 `<Navigate to="新路径" replace />` 单向重定向保留，注释中写明迁移原因与日期，不在路由表中删除旧条目。
- 静态路由清单 (`lib/routes.ts`) 同时维护 zh/en 双语文本与 pinyin/英文关键词，label 通过 `Object.defineProperty` 的 getter 延迟调用 `trInline` 以响应 locale 切换。
