模块由一个页面入口 `web/src/pages/settings/Marketplace.tsx` 和三个可复用子组件组成，职责分层清晰：
- 页面入口 `SettingsMarketplace` 是状态中心，持有 `packs`、`confirm`、`toast`、`expanded` 等 UI 状态，通过 `@/api/marketplace` 的 `listInstalledPacks/installPack/uploadPack/uninstallPack` 与后端交互，并组合出 `InstalledList`（已安装包列表）、`InstallCard`（四源安装表单）、`ConfirmModal`（安装结果二次确认）三个内联子组件。
- `CapabilitySummaryView`（`components/marketplace/CapabilitySummary.tsx`）把 `CapabilityDeclaration.summary` 渲染成 skill/agent 计数、工具类标签、binaries、config keys 及 destructive 告警，被详情页与安装确认弹窗共用。
- `CredentialBindings`（`components/marketplace/CredentialBindings.tsx`）负责 HLD-017 设计时凭证绑定：从 `@/api/secrets` 拉取可用密钥，将 pack 持久化的 `{key: credential_name}` 映射拆分为「manifest 声明槽位」和「extra: 手动附加」两类行，调用 `setPackBindings` 落盘，执行侧按凭证类型注入环境变量。
- `SignatureBadge`（`components/marketplace/SignatureBadge.tsx`）仅做 `verified/failed/unsigned` 三种签名态的轻量徽章展示。
依赖方向单向：页面 → 子组件 → `@/api/*`；子组件之间无相互引用，均通过 props 接收数据，便于在 Settings 路由下独立挂载。注册表（registry）Tab 当前隐藏但保留 case，等待后端 v1 stub 恢复后再启用。
