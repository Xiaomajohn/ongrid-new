- 国际化字符串以 `tr('中文', 'English')` 内联形式出现在调用点，而非集中字典，缺失英文可通过 grep `tr\('[^']+', *''\)` 快速发现。
- 所有面向用户的数值/时间输出统一走 `format.ts` 中的 `relativeTime` / `fullDateTime` / `formatNumber` / `clockTime`，禁止在组件里直接调用 `toLocaleString` 或 `toString`。
- CSS 变量以裸 RGB 三元组（如 `--bg: 11 11 17`）配合 `rgb(var(--token) / <alpha>)` 语法在 Tailwind 中使用，避免硬编码十六进制色值。
- 亮色主题通过 `html.light` 前缀的高特异性选择器覆盖 Tailwind 生成的 zinc 类名，dark 模式保持原样，新增覆盖需遵循同一命名约定。
