模块由一个页面组件和两个共享子组件构成，职责分层清晰：
- `ReportDetail.tsx` 作为路由页 (`/reports/:id`)，负责拉取单条报告 (`getReport`)、在 pending/generating 状态下通过 `usePoll` 每 4s 轮询刷新，并提供分享 (`shareReport`)、删除 (`deleteReport`)、导出 PDF (`window.print`) 等操作；当报告就绪后委托给 `ReportContentView` 渲染正文，并在底部展示 delivery 投递状态。
- `ReportCards.tsx` 是独立的产物列表组件，支持按 status/kind 过滤、分页 (PAGE_SIZE=20) 和定时轮询 (POLL_MS=20_000)；每个卡片通过 `ReportThumb` 懒加载 (`IntersectionObserver` + `rootMargin: '300px'`) 调用 `getReport` 获取详情，再用 CSS `scale()` 将 `THUMB_W=760` 宽度的 `ReportContentView` 缩小为缩略图预览。
- `ReportContent.tsx` 是无副作用的纯渲染组件，接收后端 `ReportContentT` JSON，将其拆成四行主题区块（集群态势/告警与处理/知识资产新增/使用情况），中间穿插 LLM narrative，并内联实现 count-up 动画、SVG sparkline、实体链接解析 (`{{entity:...}}`)，不依赖任何图表库。
依赖方向单向向下：Page → Cards → Content；所有 API 调用集中在 `@/api/reports`，i18n 统一走 `useI18n`，样式全部基于 Tailwind + `cn` 工具类。
