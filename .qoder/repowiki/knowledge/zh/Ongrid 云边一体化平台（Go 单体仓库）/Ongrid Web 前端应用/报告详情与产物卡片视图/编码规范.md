- 所有用户可见文案使用 `tr('中文', 'English')` 双参形式，禁止硬编码字符串。
- 异步数据加载采用 `useCallback` 包裹 load 函数 + `useEffect` 触发 + `usePoll(load, interval)` 轮询的模式，interval 为 0 表示关闭轮询。
- 重型子树（如缩略图中的 ReportContentView）通过 `IntersectionObserver` 延迟加载，仅在元素进入视口前 300px 才发起请求。
- 颜色语义通过集中映射表管理（`STATUS_STYLE`、`KIND_ZH/EN`、`TONE` 等 Record），UI 只查表取值，不在 JSX 中写死 class。
- 数字展示优先用本地化格式化器（`fullDateTime`、`relativeTime`、`fmtTokens`），避免直接拼接时间戳或原始数值。
