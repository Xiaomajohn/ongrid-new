- API 调用按领域拆分为 `src/api/<domain>.ts`，统一通过 `client.ts` 暴露的 fetch 实例发起请求，禁止页面直接调用原生 fetch。
- 跨页面持久化状态放入 `src/store/<feature>.ts`（Zustand），页面内临时 UI 状态使用 React useState/useReducer。
- 可复用 UI 原语放在 `components/ui/` 并统一从 `index.ts` 导出，领域专用组件按功能分组到同名子目录。
- 页面文件采用 PascalCase 命名并置于 `src/pages/` 下，路由表集中维护于 `lib/routes.ts`。
- 单元测试使用 Vitest + jsdom，MSW server 通过 `test/msw-server.ts` 启动，共享 fixture 放在 `test/fixtures/`。
