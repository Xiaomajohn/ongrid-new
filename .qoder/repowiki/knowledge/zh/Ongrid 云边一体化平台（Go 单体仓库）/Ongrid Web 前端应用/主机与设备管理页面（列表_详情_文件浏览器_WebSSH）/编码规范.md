- 对外部 API 响应进行本地类型扩展：定义 `HostDevice = Device & { ... }` 再 on-cast 赋值，在不改动 devices.ts 的前提下容忍字段缺失。
- 所有用户可见文案统一通过 `tr(zh, en)` 双参 i18n 包裹，禁止硬编码中英文字符串。
- 权限判断集中使用 `usePermissions().canMutate`，对只读账号在按钮层提前 disabled 并给出 tooltip/aria-label 说明原因。
- 异步副作用一律采用 `let cancelled = false; useEffect(() => {... return () => { cancelled = true; }}` 模式防止竞态。
- 错误提示统一渲染为带 `role="alert"`、红色边框/背景的 `<div>` 块，位于内容区顶部。
- 需要跨 render 存活的副作用对象（WS、XTerminalApi、pumpRef、sizeRef、closedSentRef）一律通过 useRef 持有，避免闭包过期。
