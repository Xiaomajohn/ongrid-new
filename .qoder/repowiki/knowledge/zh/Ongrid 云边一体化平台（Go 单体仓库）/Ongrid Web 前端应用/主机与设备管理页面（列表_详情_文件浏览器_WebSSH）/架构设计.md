本模块由四个并列的 React 页面组件组成，分别挂载到 /hosts、/hosts/:hostId、/devices/:id/files、/devices/:deviceId/shell[-direct] 及 /hosts/:hostId/shell[-direct] 路由：
- Hosts.tsx：设备列表页，使用 usePoll(10s) 轮询 listDevices，并在内存中按 device_id 聚合 edges 计数；通过本地 wrapper updateDeviceRolesLocal/listDeviceEdgesLocal 直接调用 /devices/{id}/roles 与 /devices/{id}/edges，避免依赖尚未导出的 devices.ts 函数。
- HostDetail.tsx：三 Tab（basic/topology/meta），复用 @/components/DeviceTopology 渲染拓扑，BasicTab 以网格展示 OS/CPU/Mem/Disk/Fingerprint 等扩展字段，MetaTab 用 buildMeta 把 HostDevice 扁平化为 JSON 卡片。
- DeviceFiles.tsx：仅做设备元数据获取与错误处理壳，实际 SFTP 树/上传/编辑逻辑下沉到 @/components/FileBrowser，通过 deviceId + initialPath="/" 注入。
- DeviceShell.tsx：基于 WebSocket 的 WebSSH 全屏终端，支持两条传输路径——/shell（经 edge-tunnel）与 /shell-direct（直连设备 IP），通过 location.pathname 后缀判定 ShellRoute；连接前走 probeShellPreflight 预检 HTTP 状态，onmessage 解析控制帧（ready/auth_error/exit）并驱动 ConnState 机。

依赖方向单向向下：pages → @/api/*（devices/edges/webshell/client）、@/components/*（Modal/StatusPill/FileBrowser/XTerminal/DeviceTopology）、@/store/me（usePermissions）、@/i18n/locale（tr）。模块内部无子目录，所有交互逻辑均内联于各自 .tsx 文件中，未抽取 hooks 或 store。
