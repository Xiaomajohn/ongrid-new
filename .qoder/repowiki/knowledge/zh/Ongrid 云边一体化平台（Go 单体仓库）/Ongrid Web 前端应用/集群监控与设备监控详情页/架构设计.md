模块由两个页面组件和三个可复用子组件构成，职责分层清晰：
- `Monitor.tsx` 是入口，负责路由参数（range / refresh / role / device）、设备角色映射、自动刷新 tick 广播、内置 10 个硬编码 GrafanaPanel 定义（CPU/内存/磁盘/网络/Top8进程/负载饱和度/磁盘IO/conntrack/TCP），并通过 `injectDeviceIDFilter` 把 role/device 筛选注入到每个 PromQL target；同时从 `/v1/monitor/panels` 拉取用户面板并透传给 `UserPanelGrid`。
- `MonitorDeviceDetail.tsx` 是 `/hosts/:hostId/monitor` 的设备级详情页，按「指标/探针/元数据」三个 tab 分别渲染 `DeviceMetricsPanels`、`MonitorDeviceProbes` 与本地 JSON 卡片，与主机详情页形成显式视角对。
- `components/monitor/` 下的三个组件只关注展示：`PanelGrid` 将 GrafanaPanel 数组以 24 列 CSS grid 布局渲染为 `PromQLPanel`，并在 <1200px 时折叠为单列；`UserPanelGrid` 在相同网格上叠加编辑/删除悬浮按钮与「已筛选/全集群」状态徽章；`ProcessTopPanel` 独立使用 recharts 直接查询 process-exporter 的 `namedprocess_namegroup_*` 指标，仅当选中单台设备时显示。
依赖方向单向向下：页面 → monitor 子组件 → 共享的 `@/components/PromQLPanel` 与 `@/api/prom`，不反向引用页面逻辑。
