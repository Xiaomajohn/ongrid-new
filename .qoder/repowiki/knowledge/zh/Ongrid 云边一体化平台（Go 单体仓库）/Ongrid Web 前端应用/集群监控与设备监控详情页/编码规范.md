- 所有面向用户的文案统一通过 `tr('中文', 'English')` 调用 i18n，禁止内联字符串常量。
- PromQL 表达式中必须保留 `{}` 锚点以便 `injectDeviceIDFilter` 注入 `device_id=~"..."` 匹配器，避免裸 metric 名导致筛选被静默丢弃。
- 异步请求一律采用 `let cancelled = false;` + 清理函数模式，在 useEffect 返回的清理回调中置位 cancelled 防止竞态。
- GrafanaPanel 的 id 采用固定区间隔离：内置面板用 1..10，用户面板通过 `100000 + p.id` 偏移，避免与硬编码 ID 冲突。
- 响应式布局通过监听 `window.innerWidth < 1200` 切换 24 列 grid 与单列模式，gridAutoRows 固定 36px 对应 Grafana grid unit。
