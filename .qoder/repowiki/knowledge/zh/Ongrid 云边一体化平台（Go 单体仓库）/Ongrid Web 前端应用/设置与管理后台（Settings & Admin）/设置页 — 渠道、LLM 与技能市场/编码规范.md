- 所有用户可见文案使用 `tr('中文', 'English')` 双参形式，配合 useI18n() 实现中英切换。
- 异步操作统一 try/catch 捕获 ApiError，错误信息写入本地 err 状态并以红色边框区块展示。
- 敏感输入（app_secret、API Key）默认 password 类型，通过 Eye/EyeOff 按钮切换 revealed 状态显示明文。
- Provider/平台元数据集中声明为常量对象或数组（PROVIDER_META、LLM_PROVIDERS、TABS），UI 据此渲染选项与提示。
- 删除/卸载等破坏性操作先弹出 Modal 二次确认，再执行 API 并刷新列表。
