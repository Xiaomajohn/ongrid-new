三个并列的 React 页面组件，均挂载在 /settings/* 路由下，由外部 SettingsLayout 统一包裹：
- Channels.tsx：IM App 的 CRUD 列表 + Modal 编辑器，通过 `@/api/imbridge` 调用后端 IMBridge 接口；按 provider 枚举（feishu/dingtalk/telegram/slack）驱动表单字段与模式（stream/webhook）选择。
- LLM.tsx：以 ProviderMeta 数组驱动的多卡片配置器，每个 provider 对应一组 system_settings.llm.* 键（keyAPIKey/keyBaseURL/keyModels/keyDefaultModel），保存后调用 `invalidateLLMRouter` 触发 manager 缓存失效。
- Marketplace.tsx：已安装包列表 + 四源安装（upload/local/tarball/git）+ 安装后确认弹窗（含回滚卸载），依赖 `@/api/marketplace` 与 `@/components/marketplace/*` 子组件（CapabilitySummaryView、CredentialBindings、SignatureBadge）。

依赖方向：页面 → `@/api/*`（imbridge/settings/marketplace）→ 共享 UI 组件（Modal、Button、Card、Chip、EmptyState）→ i18n（useI18n/tr）。Marketplace 额外依赖 `@/store/auth` 做 admin 权限门控。三个文件彼此独立，无跨文件 import。
