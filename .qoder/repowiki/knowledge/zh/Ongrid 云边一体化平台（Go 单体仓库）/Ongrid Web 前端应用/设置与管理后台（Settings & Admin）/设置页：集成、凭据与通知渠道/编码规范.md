- 所有对外 API 调用统一用 try/catch 包裹，错误对象经 `e instanceof ApiError ? e.message : (e as Error).message` 归一化为字符串后写入 err 状态显示。
- 需要回显的敏感字段采用 server/draft 双份状态 + revealSetting 并行解密模式，输入默认 type=password，通过 eye 图标切换 revealed 标志暴露明文。
- 保存按钮受 dirty 标记控制（draft 与 server 逐字段比较），仅在存在差异时启用，避免无意义请求。
- 长文案使用 `useI18n()` 的 `tr(zh, en)` 双参调用，键值对同时提供中英文占位，禁止硬编码 UI 文本。
- 异步操作（保存/测试/同步）期间用 loading/saving/testing 布尔或 discriminated union 状态驱动按钮禁用与 spinner，完成后重置状态。
