三个独立的 React 函数组件文件，均作为 Settings 布局下的叶子路由渲染，彼此无直接依赖，仅共享 `@/i18n/locale`、`@/api/client`、`@/components/ui` 等全局设施。
- `Integrations.tsx`：以四个 Card（Prometheus / Grafana / Loki / Tempo + WebSearch）为组织单元，每个 Card 内部维护 server/draft/revealed/saving/probe 状态，通过 `listSettings('prom'|'grafana'|'loki'|'tempo')` 拉取 system_settings，敏感字段走 `revealSetting` 并行解密；Grafana 额外调用 `testGrafanaConnection`/`syncGrafana` 并联动 `invalidateGrafanaRootCache` 刷新 drilldown 缓存。
- `Secrets.tsx`：凭据库页面，先并发 `listSecrets` + `listCredentialTypes`，按 `type` 动态渲染 typed fields 或 custom key/value 行，提交时聚合为 `{fields}` 调用 `createSecret`，删除走 `deleteSecret`。
- `Notifications.tsx`：按 `TYPE_CARDS` 声明式驱动各 IM/Webhook 类型卡片，支持按 locale 排序（中文优先飞书/钉钉/企微，英文优先 Slack/Telegram），CRUD 通过 `@/api/alerts` 的 `list/create/update/delete/testChannel`，测试消息结果以 toast 形式展示。
依赖方向单向向外：UI → `@/api/*` → 后端 REST；不持有跨页面状态，所有持久化由后端完成。
