本模块由两个并列的布局组件构成：
- `SettingsLayout` 负责 `/settings/*` 下的产品级配置（健康、升级、集成、凭证、通知、渠道、LLM、Agent、偏好、关于），左侧 rail 以 `RAIL_ITEMS` 常量驱动 NavLink + Outlet 渲染子页面。
- `AdminLayout` 负责 `/admin/*` 下的平台治理（用户、组织、审计日志、Webshell），同样以 `railItems()` 生成导航项并通过 Outlet 挂载叶子路由。

两者共享同一套 UI 契约：`PageHeader` 标题栏 + 左侧可滚动 rail + 右侧内容区；都使用本地 `Suspense` 包裹 `<Outlet />` 以避免懒加载子路由时整壳重渲染；都在入口用 `usePermissions().isAdmin` 做路由级权限门控，非管理员直接返回 `EmptyState`。所有叶子页面仅关注自身表单/表格逻辑，不感知布局差异，由这两个 Layout 在路由层完成装配。
