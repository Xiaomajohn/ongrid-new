三个独立 React 组件文件，均作为 SettingsLayout 下的路由叶子挂载：
- `Webshell.tsx`：WebSSH 会话审计列表，通过 `@/api/webshell`（`listShellSessions` / `killShellSession`）拉取并管理活跃/历史会话，同时并发拉取 `@/api/users` 和 `@/api/edges` 做用户/设备名映射；内置 5s tick 驱动持续时间刷新，管理员可强制终止会话。
- `Agent.tsx`：基于通用系统设置 API `@/api/settings`（`listSettings` / `setSetting`）读写 `agent/write_enabled` 键，控制 AI 助理是否暴露写入工具。
- `Preferences.tsx`：纯前端偏好面板，通过 Zustand store `@/store/theme`（accentId）、`@/store/mode`（theme preference）和 i18n `useI18n` 切换语言、明暗模式与品牌色。
依赖方向单向指向 `@/api/*`、`@/store/*`、`@/i18n/locale`、`@/components/ui` 与 `@/lib/cn`，本模块不持有跨页面状态。
