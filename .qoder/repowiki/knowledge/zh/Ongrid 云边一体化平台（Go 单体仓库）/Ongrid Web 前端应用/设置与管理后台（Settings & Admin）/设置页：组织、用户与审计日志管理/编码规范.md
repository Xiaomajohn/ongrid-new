- 所有用户可见文案使用 `tr('中文', 'English')` 双参形式，配合 `useI18n()` 的 `tr` 或 `trInline` 进行 i18n。
- 异步副作用统一包裹 try/catch，错误经 `errMsg(e)` 归一化为字符串后写入局部 error state，成功则用 `{ kind: 'ok'|'err', text }` 的 toast 提示并在 4s 后自动清除。
- 弹窗采用「open 布尔 + target 对象」的双态控制：如 `setCreateOrgOpen(true)` 打开新建模态，`setEditOrg(selected)` 传递目标数据，关闭时置空 target/open。
- 表格行操作优先使用 Chip 展示状态（success/warning/info/accent/default tone），危险操作按钮一律带 `variant="danger"` 并附带确认 Modal。
- 需要权限控制的页面在组件顶部读取 `useMe()`，若 `me.role !== 'admin'` 直接返回 EmptyState 且不再发起任何 API 请求。
