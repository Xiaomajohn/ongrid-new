本模块由三个独立的 React 函数组件文件组成，每个文件对应一个路由页面，遵循相同的单文件自包含模式：
- Orgs.tsx：双栏布局（左列组织树 + 右列成员表），通过 `@/api/orgs` 和 `@/api/users` 调用后端；内置 `flattenOrgTree` / `descendantIDs` 等纯函数在本地计算 parent_id 树并防环；默认组织名硬编码为 `DEFAULT_ORG_NAME = '默认组织'`，前端据此禁用删除。
- Users.tsx：基于 `useMe()` 的 `role === 'admin'` 守卫，非管理员直接返回 EmptyState；行操作集中在 kebab 菜单并通过 `createPortal` 渲染到 `document.body` 避免被 `overflow-x-auto` 裁剪。
- AuditLog.tsx：只读列表 + 右侧 Drawer 详情，action/resource 标签通过模块内 `ACTION_LABELS` / `RESOURCE_LABELS` 映射，注释要求与后端 `internal/manager/model/audit/log.go` 保持同步。
依赖方向单向向外：仅消费 `@/api/*`、`@/components/ui`、`@/store/me`、`@/i18n/locale`，不反向依赖其他页面或 store。
