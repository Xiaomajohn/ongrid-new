- 所有用户可见文案统一通过 `useI18n().tr('中文', 'English')` 双参形式注入，避免硬编码字符串。
- 异步数据加载采用 `useCallback` 包装 `run(manual?)` + `useEffect(() => void run(), [])` 模式，并在 finally 中用 `MIN_MANUAL_REFRESH_MS = 650` 节流手动刷新按钮。
- 错误处理走 `ApiError` 类型守卫，捕获后写入 `err` state 并以红色边框卡片内联展示。
- UI 状态（loading / err / data）三态分离：`loading && !data` 显示带 Loader2 的占位 Card，`!loading && !data` 显示空态提示，有数据时再渲染详情。
- 视觉语义通过集中常量表驱动：`STATUS_META`、`GROUP_META`、`CHECK_LABELS`、`DETAIL_LABELS`、`getStatus()` 等 Record 把状态→图标/颜色/标签的映射从 JSX 中抽离。
