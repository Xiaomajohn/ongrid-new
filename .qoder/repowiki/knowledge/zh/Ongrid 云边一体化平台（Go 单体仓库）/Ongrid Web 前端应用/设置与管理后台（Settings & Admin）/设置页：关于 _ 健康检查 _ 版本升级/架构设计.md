三个独立的 React 函数组件（About / Health / Upgrade），作为 Settings 路由下的叶子页面，各自负责一个管理功能：
- About.tsx：通过 `@/api/version` 拉取 `manager_version`，配合 `OngridLogo`、`Github`/`Scale` 图标展示产品身份。
- Health.tsx：调用 `runSystemHealthCheck()` 获取 `HealthReport`，按 `GROUP_ORDER` 将 checks 分组渲染为 `HealthGroup` → `HealthRow`，异常项支持展开查看 message/details；状态映射集中在 `STATUS_META`、分组映射在 `GROUP_META`、键值标签在 `CHECK_LABELS`/`DETAIL_LABELS` 中声明式维护。
- Upgrade.tsx：调用 `checkSystemUpgrade()` 返回 `UpgradeInfo`，根据 `comparison_supported`/`update_available` 计算 `getStatus()` 并渲染 `VersionSummary`、`UpgradeState`、`CommandList`，提供 `copyText` 兼容旧浏览器的剪贴板回退。
依赖方向单向指向 `@/api/*`、`@/components/ui`（Card/Button）、`@/i18n/locale`、`@/lib/cn`、`@/lib/icon`，页面之间无互相引用。
