- 所有用户可见文案一律通过 `tr('中文', 'English')` 双语文法包裹，禁止硬编码字符串。
- 异步请求统一采用 `loading/refreshing/err` 三态本地 state，错误信息经 `e instanceof ApiError ? e.message : (e as Error).message` 归一化后展示。
- 需要后台变更的操作（ack/resolve/silence/toggle/delete）成功后都显式调用一次 `fetchXxx({ silent: true })` 刷新列表，并与 `refreshBadge()` 保持侧边栏红点同步。
- UI 行为受 `usePermissions().canMutate` 控制：只读账号的按钮置灰并附带 `viewerTip` 提示，后端仍会返回 403 兜底。
- 长文本字段（summary、runbook、AI 报告）使用 `truncate` + `title` 或 `ReactMarkdown` 展开，避免表格行溢出。
- 颜色语义通过集中常量（如 `SOURCE_PILL_STYLE`、`SeverityBadge`/`StatusBadge` 的样式分支）维护，不在 JSX 中散落重复 class 字符串。
