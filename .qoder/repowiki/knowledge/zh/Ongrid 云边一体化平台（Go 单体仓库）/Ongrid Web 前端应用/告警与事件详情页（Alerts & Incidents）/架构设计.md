三个文件各自作为独立 React 路由页组件，通过 `react-router-dom` 的 `<Link>` 与 `useParams` 在 `/alerts`、`/alerts/rules`、`/alerts/incidents/:id` 之间跳转。

- `Alerts.tsx`：列表页，使用 `usePoll(30s)` 轮询 `listIncidents`，本地按 status/severity 过滤；通过 `listEdges()` 一次性拉取设备名映射以渲染 Target 列；全局未确认计数来自 `useIncidentBadge` store，避免与本地过滤结果不一致。
- `AlertRules.tsx`：规则管理页，内置 `RuleEditorModalInner` 多步骤表单（基本信息 → 类型选择 → 条件编辑 → 级别与通知），调用 `previewRule` 做 PromQL/日志/链路表达式的前端试算并借助 `recharts` 渲染曲线；仅管理员可写，非管理员按钮带 `disabled` + tooltip 提示。
- `IncidentDetail.tsx`：incident 详情页，并行拉取 `getIncident` + `listIncidentEvents`，并在首次 90s 内用 5s 快速轮询等待 AI 初查事件落地；包含 InvestigationReportPanel（自动/手动触发根因分析）、AIInitialDiagnosisPanel、AgentTimelinePanel、Timeline/Sidebar2 等子面板，并通过 `openObservabilityUrl` / `buildExploreUrl` 跳转到 Grafana/Loki/Tempo。

依赖方向：页面 → `@/api/alerts`（CRUD + 类型定义）→ `@/api/client`（ApiError）→ `@/store/*`（权限、badge、observability）→ `@/components/Modal`、`@/lib/*`（i18n、时间格式化、URL 拼接）。模块内部无共享状态，各页自管本地 state。
