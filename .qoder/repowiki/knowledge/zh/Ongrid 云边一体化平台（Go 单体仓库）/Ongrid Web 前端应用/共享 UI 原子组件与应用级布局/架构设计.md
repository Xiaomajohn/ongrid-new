模块由两层组成：
- `components/ui/`：纯展示型原子组件（Button、Card、Chip、EmptyState、PageHeader、RoleSelect），通过 `index.ts` barrel 统一导出，供页面按“视觉一致性”约束引用，避免各页面自行拼装 className。
- `Layout.tsx` + `Sidebar.tsx`：应用级布局容器。`Layout` 作为路由根包裹 `<Outlet />`，在挂载时启动未确认告警计数轮询、绑定 ⌘K/⌘P 全局热键，并渲染 `CommandPalette` 与 `AgentSidePanel`；`Sidebar` 负责折叠态/展开态双形态导航、用户菜单、会话列表（含重命名/删除）、可折叠分组（状态持久化到 localStorage）以及基于 URL search params 的自定义 active 匹配逻辑。
依赖方向单向向外：UI 原子组件仅依赖 `@/lib/cn`；布局组件订阅 `@/store/*`（ui、auth、incidentBadge、me、chatSessions）并调用 `@/api/*` 与 `@/i18n/locale`，不反向被 ui 子目录引用。
