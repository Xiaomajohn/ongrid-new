- 所有 UI 原子组件通过 `forwardRef` 暴露原生 ref，并以 `{ variant, className, ...rest }` 形式透传 HTML 属性，保持与原生元素 API 一致。
- 组件内部样式一律用 `cn(...)` 拼接 Tailwind 类名，禁止直接写字符串模板拼接 class。
- 多语言文案统一通过 `useI18n()` 的 `tr('中文', 'English')` 调用，并在注释中保留中英文对照，确保 i18n 切换后即时更新。
- 副作用（事件监听、轮询、localStorage 读写）在 `useEffect` 中注册并在返回函数中清理，避免内存泄漏。
- 可折叠分组的状态以 `sidebar.section.<storageKey>` 为 key 写入 localStorage，并提供 `defaultOpen` 降级回退。
