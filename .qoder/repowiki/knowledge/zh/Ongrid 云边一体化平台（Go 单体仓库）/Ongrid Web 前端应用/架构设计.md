本模块是单一 Vite 构建的前端 SPA，以 `src/main.tsx` 启动、`App.tsx` 注册全局路由，将业务拆分为多个领域子目录（pages/*、components/*），各子域通过以下横切机制协作：
- 网络层：所有页面/组件统一调用 `src/api/*.ts` 中由 `client.ts` 封装的 fetch 实例，自动注入 access_token、处理 401 刷新与错误码。
- 状态层：认证态、主题、模型选择等跨页面数据集中在 `src/store/*.ts`（Zustand），被 pages 与 components 共同订阅。
- UI 层：`components/ui/` 提供原子原语，`Layout.tsx` + `Sidebar.tsx` 组合成应用壳层，承载全局快捷键、命令面板与侧边导航；领域特定组件下沉到 `components/{marketplace,monitor,topology}/` 并按需懒加载。
- 国际化与样式：`i18n/locale.ts` 与 `styles/index.css`（Tailwind + 暗/亮双主题）为全应用共享。
- 测试：`test/setup.ts` + `msw-server.ts` 为各页面单元测试提供 jsdom/Vitest 环境与 MSW 拦截，fixture 集中在 `test/fixtures/`。
构建产物输出至 `dist/`，静态资源位于 `public/`，Vite 配置在根级 `vite.config.ts` 与 `vitest.config.ts` 统一管理。
