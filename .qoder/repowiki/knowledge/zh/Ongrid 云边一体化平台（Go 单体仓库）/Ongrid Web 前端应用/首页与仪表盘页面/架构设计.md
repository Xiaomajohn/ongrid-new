三个同级 React 函数组件，分别作为独立路由页面挂载：
- `Home.tsx`：登录后的默认入口，负责问候语 + ChatInput 输入框 + PromptCard 快捷提示；通过 `createSession` 创建会话并导航到 `/chat/:id`，同时把选中的 LLM provider/model 持久化到全局 store 和后端 settings（`default_provider` + `<provider>_default_model`），并在 mount 时拉取 `listEdges`/`listModels` 以决定空设备态或 prompt 卡片展示。
- `Dashboard.tsx`：聚合型仪表板，集中调用 `listEdges`、`promQueryRange`（PromQL）、`listSessions`、`listIncidents`、`GET /usage/today`，用 `usePoll(REFRESH_MS=60s)` 定时刷新；内部按视觉分区组织为 KPI strip → ClusterTrend（手写 SVG 折线）+ ClusterPosture（recharts 柱状图）→ AlertSeverityCard（donut）+ NoisyRulesCard（横向 bar chart）等子组件，全部在文件内定义，不拆分子模块。
- `PageView.tsx`：轻量全屏 viewer，从 `@/api/pages.fetchPageHTML` 拉取 HTML 后以 `srcDoc` 注入带 `sandbox="allow-popups allow-downloads"` 的 iframe，用于在新标签页中打开产物页面。
依赖方向单向向外：仅消费 `@/api/*`、`@/components/*`、`@/store/*`、`@/i18n/locale`、`@/lib/*`，自身不导出任何供其他页面复用的逻辑。
