模块由一个页面入口和两个可复用子组件构成，依赖方向单向：`web/src/pages/Topology.tsx` → `@/components/topology/*` → `@/api/topology`。

- `Topology.tsx` 是路由级页面，通过 `TabButton` 在三个视图间切换：
  - `graph`：渲染 `<TopologyGraph>`（来自 `Graph.tsx`）；
  - `nodes`：实现节点列表、按 type 的 chip 过滤、搜索、右侧 `NodeDetailDrawer`（展示邻居关系、删除节点、添加关系弹窗）；
  - `relation-types`：上下两块——`NodeTypesPanel`（注册/删除自定义 NodeType）与 `RelationTypesTab`（管理 RelationType）。
- `Graph.tsx` 封装 `react-flow` + `@dagrejs/dagre`，将 `TopologyNode[]` / `TopologyRelation[]` 转换为 RF 的 nodes/edges；布局采用 TB 方向的 dagre 计算 X，再按 `TYPE_TIER` 把节点 snap 到固定水平分层带，形成“应用→服务→集群→主机→机架”的层级图；边颜色映射到 `RelationType.semantics_tag`，虚线样式区分 containment/dependency/observation 等语义。
- `NodeNeighbors.tsx` 是独立卡片组件，被 EdgeDetail 与 Incident “影响面”面板复用，内部并行拉取中心节点、邻居关系、关系类型并对端节点做 hydrate，不依赖 Topology 页面状态。

数据流全部走 `@/api/topology` 导出的 CRUD 函数（`listNodes`、`createNode`、`deleteRelation` 等），页面内使用 React `useState`/`useEffect`/`useMemo` 本地缓存，无全局 store 接入。
