- Wiki 页面中由 AI 生成的内容必须包裹在 HTML 注释块 BEGIN:REPO_WIKI_MANAGED / END:REPO_WIKI_MANAGED 内，以便增量更新时只重写受管区块。
- 所有技术声明使用脚注形式标注来源，格式为相对路径加行号范围并附带 commit sha，并在可用时转为 GitHub Permalink。
- repowiki/.repo_wiki/state.json 中每个页面条目以 managed_sections 数组列出对应 H2 标题，作为增量更新时的锚点匹配依据。
- Agent Skill 子目录统一以 SKILL.md 作为入口，并通过 YAML front matter 声明 name/description/license/compatibility/metadata/allowed-tools。
