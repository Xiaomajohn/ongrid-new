本模块由三块组成：
- docs/：人类维护的项目级文档（安装、工程结构、测试目录等），独立于 Wiki 生成流程。
- repowiki/：MkDocs Material 站点源码，mkdocs.yml 定义导航树（首页、快速开始、架构、组件、API、运维、ADR），docs_dir=docs、site_dir=site；site/ 为构建产物，.repo_wiki/ 存放运行时状态（state.json 记录每个页面的 managed_sections 与 last_generated_commit、manifest.json 记录引用指纹、code_index.json/components.txt/file_list.txt 为索引）。
- .agents/skills/repo-wiki/：Agent Skill 套件，包含初始化、索引、生成、变更检测、增量更新、校验六个子 SKILL.md，以及 Python 辅助脚本（detect_managed_blocks.py、validate_citations.py、generate_permalinks.py、compute_page_impact.py）和页面模板（assets/templates/*.template）。

依赖方向：Skill 脚本 -> Git + 文件系统 -> 读取 repowiki/.repo_wiki/state.json 做增量决策 -> 写入 docs/*.md（仅覆盖受管区块标记内的内容）-> mkdocs build 产出 repowiki/site/。人类编辑位于受管区块之外的内容被保留。
