模块按业务域划分目录：`iam/v1`（身份与组织）、`manager/{edge,metric,aiops,alert,notification}/v1`（管理面服务）、`tunnel/v1`（边缘→云端 geminio 通道）。每个 `.proto` 文件对应一个独立包，package 遵循 `ongrid.<bc>[.<subdomain>].v<major>` 命名；`go_package` 指向 `github.com/singchia/ongrid/api/gen/<path>/v1;<pkg>v1`，由根级 `buf.yaml`(v2, STANDARD lint + FILE breaking) 与 `buf.gen.yaml` 驱动，使用远程插件 `protocolbuffers/go:v1.34.2` 与 `grpc/go:v1.5.1`（启用 `require_unimplemented_servers=true`）生成到 `api/gen/`（gitignore）。MVP 阶段不引入 grpc-gateway，REST 路由在 `internal/*/server/` 手工实现；`tunnel/v1` 明确声明不使用 gRPC service，仅承载 JSON 编码的请求/响应体，通过 geminio End 对象按方法名注册。各 proto 之间刻意避免跨包 import（如 tunnel 复制 HostInfo），保证版本演进独立。
