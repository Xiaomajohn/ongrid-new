- 每个 RPC 都拥有独立的 Request / Response message，即使为空也不复用，以保证前向兼容。
- ID 统一使用 `uint64`，时间戳使用 `google.protobuf.Timestamp`，令牌类字段用 `string`。
- `org_id` 绝不作为用户可传入的请求字段，而是从 JWT claims 或 URL path 经 `internal/pkg/auth` 中间件注入；仅在响应中只读回显。
- `optional` 字段谨慎使用，仅在存在性对负载语义有决定性影响时才声明。
- 每个服务的消息集中在单个 `.proto` 文件中，禁止拆分为多个文件。
- 跨域共享类型（如 HostInfo、HostMetricPoint）在依赖方 proto 中复制而非 import，保持各 proto 自包含与独立演进。
