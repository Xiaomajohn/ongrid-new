- 所有 CI、Dockerfile、README 仅调用 make target，禁止裸 go build / docker build
- 对外 RPC/隧道消息统一写在 api_protos/*.proto，由 buf 生成 Go stub 作为 REST 路由与 geminio 调用的唯一事实来源
- manager 与 edgeagent 共享 internal/pkg 与 internal/skill 中的认证、配置、Tunnel RPC、DB 迁移与 skill 框架，禁止各自重复实现
- 测试通过 build tag 区分：单元测试 `go test ./...`，集成测试 `-tags=integration`，E2E `-tags=e2e` 并支持 E2E_LIVE_ALL=1 打通真实外部服务
- 版本注入统一通过 LDFLAGS -X main.version=$(VERSION) 从 VERSION 文件注入，所有二进制输出到 bin/<os>-<arch>/ 目录
