- 仓储实现通过 `var _ biz.Repo = (*Repo)(nil)` 在编译期校验接口一致性，接口定义放在 biz 包、实现在 data 包，禁止 service 直接 import data。
- 所有 GORM 查询失败统一映射为 `errs.ErrNotFound`，更新类方法通过 `RowsAffected == 0` 判断不存在行，错误类型集中在 `internal/pkg/errs`。
- 模型列名使用 gorm tag 显式指定（如 `column:pass_hash`、`column:display_name`），并通过 `TableName()` 固定表名，避免依赖约定命名。
- 敏感字段（PassHash）在 Usecase 返回前一律清空，防止意外泄露到 JSON 响应或日志。
- Casbin 主体/域 ID 全部经 `uidStr`/`oidStr` 转为十进制字符串，确保 g/p 规则形状一致，杜绝混用 uint/字符串导致的匹配失败。
- 可选能力（org/membership/authz）通过 post-construction `Set*` 注入且 getter 允许 nil，未接线时返回 503 而非 panic，保障渐进上线。
