- install.sh 与 upgrade.sh 各自内联复制了 `detect_host_proxy` / `collect_internal_no_proxy_domains` / `generate_self_signed_tls_cert` 等函数，而非通过 source 共享，以保证两个脚本均可独立从提取出的 tarball 中直接执行。
- 所有运行时配置集中在 `${INSTALL_DIR}/.env`（权限 600），脚本通过 `set_env_value` 以 `sed -i.bak` 就地更新已有 key 或在末尾追加新 key，禁止覆盖运维已填写的值。
- Compose 服务统一声明在 `ongrid_net` bridge 网络下，对外端口仅在需要调试时显式 `ports:` 映射（如 prometheus 9090、nginx 443/80），其余内部服务（loki/tempo/qdrant/grafana）仅通过容器名在 compose 网络内访问。
- 环境变量采用 `${VAR:-default}` 形式在 compose 中给出默认值，同时由 install/upgrade 脚本把 host 探测到的 `HTTP_PROXY`/`HTTPS_PROXY`/`NO_PROXY` 写入 `.env` 中的 `ONGRID_HTTP_PROXY`/`ONGRID_HTTPS_PROXY`/`ONGRID_NO_PROXY`，再由 compose 注入到 ongrid 与 searxng 两个服务。
