- 所有 e2e 测试文件以 `//go:build e2e` 标签开头，确保不被 `go test ./...` 默认包含。
- 需要真实外部凭据的测试统一通过 `testenv.RequireSecret(t, "VAR_NAME")` 获取，缺失时以固定格式的 `SKIP:` 消息跳过，避免 CI 失败。
- 每个 e2e 测试文件对应 `docs/test/e2e-catalog.md` 中的一行编号用例，文件名形如 `<area>_<short>_test.go`，便于按编号定位回归。
- 对外部服务访问采用“默认 fake、可选 live”的双模式：fake 始终创建但 live 模式下忽略其 URL，由 secrets 注入真实地址。
- 测试中涉及敏感值的日志一律经 `testenv.RedactSecret` 脱敏后再输出。
