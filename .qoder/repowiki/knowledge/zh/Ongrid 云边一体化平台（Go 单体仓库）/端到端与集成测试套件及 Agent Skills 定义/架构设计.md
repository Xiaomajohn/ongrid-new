本模块由两个互不依赖的子目录组成：
- `tests/e2e/`：通过 `//go:build e2e` 标签隔离，`main_test.go` 中的 `TestMain` 负责在进程退出时调用 `testenv.TerminateSharedMySQL()` 回收 testcontainers 的 MySQL 8.0 容器；`testenv/` 是共享基础设施层，`Start(t)` 一次性构建 `cmd/ongrid`、启动一个随机端口的新进程、轮询 `/healthz` 就绪，并注入 LLM/Slack/Telegram/Prom/Loki 等 `httptest.Server` fake；每个测试用 `defer env.Stop()` 清理，跨测试共享同一 MySQL 实例并通过 `startMu` 串行化 schema 初始化。
- `tests/integration/`：无外部进程，使用 `gorm + sqlite(:memory:)` 直接拼装 biz usecase + store，验证“凭证加密 → 审批流 → executor 注入 → Runner 执行”的 HLD-017 完整链路。
- `skills/<name>/SKILL.md`：YAML frontmatter + Markdown 正文，被 manager/edgeagent 作为 agent skill 注册表加载，描述工具名、read-only 策略、edge capabilities 白名单等元数据。
