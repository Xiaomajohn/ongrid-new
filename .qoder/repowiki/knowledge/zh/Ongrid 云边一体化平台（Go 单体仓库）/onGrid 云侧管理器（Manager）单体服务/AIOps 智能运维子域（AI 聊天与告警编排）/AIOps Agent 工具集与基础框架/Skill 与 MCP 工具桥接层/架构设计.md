本模块位于 `internal/manager/biz/aiops/tools` 包内，承担双向桥接职责：
- `skill_bridge.go`：遍历全局 `skillcore.AllByClass(ClassSafe)`，把每个安全 Skill 包装成 `basetool.Tool` 注入到 `Registry`；对 `ScopeHost` 的 Skill 在 JSON Schema 中强制注入 `device_id`（兼容旧别名 `edge_id`），执行时通过 `resolveEdgeForDeviceID` 经 `DeviceResolver` 解析为 host edge_id，再以 system 身份调用 `skillsvc.Service.Execute`。
- `mcp_basetool.go`：定义 `MCPCaller`/`MCPProposer` 两个窄接口，构造 `MCPTool` 适配器实现 `basetool.BaseTool`；wire name 形如 `mcp__<server>__<tool>`（由 `sanitizeMCPSeg` 清洗），按名称动词启发式推断风险类（destructive/read），trusted 路径走同步 `CallMCPTool`，否则走 `ProposeMCPCall` 进入人机审批队列。
- `inventory_bridge.go`：逆向遍历 `ToolBag` 中的全部 `BaseTool`，跳过已在 skill 侧存在的同名项，将其包装为 `baseToolSkillExecutor`（实现 `skill.Executor` + `RawSchemaProvider`）注册进全局 skill 注册表，使 `/skills` 页面能统一展示云侧工具并带审计与 class gate。
依赖方向单向向外：仅依赖 `basetool`、`skillcore`、`skillsvc` 以及共享的 `DeviceResolver`，不反向依赖上层编排逻辑。
