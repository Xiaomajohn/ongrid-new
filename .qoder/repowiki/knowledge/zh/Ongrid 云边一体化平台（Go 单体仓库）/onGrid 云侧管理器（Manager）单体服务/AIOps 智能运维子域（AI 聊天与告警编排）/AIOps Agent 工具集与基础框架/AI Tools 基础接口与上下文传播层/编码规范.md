- 每个上下文值使用私有 struct key 类型（如 sessionIDCtxKeyT{}）+ 包级变量导出 WithXxx / XxxFromContext 一对函数，禁止直接读写 context.Value。
- WithXxx 在传入空值时直接返回原 ctx 作为 no-op，读取端对缺失键一律回退到安全默认（""、false、nil）。
- InvokeOption 采用函数式选项模式：可变 invokeConfig 内部结构 + ResolveOptions 聚合器 + Resolved 只读导出，装饰器通过该通道注入 tenant/user/device 等调用期上下文。
- 动态来源通过 ToolInfo.Origin 标记（OriginBuiltin/OriginMCP/OriginSkill）而非按名称前缀匹配，新增来源只需加一个常量即可被 IsDynamic() 自动识别。
