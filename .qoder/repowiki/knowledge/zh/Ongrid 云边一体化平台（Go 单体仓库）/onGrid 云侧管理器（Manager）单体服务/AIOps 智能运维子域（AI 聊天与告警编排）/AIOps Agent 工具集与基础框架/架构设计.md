本模块按职责拆分为四层，通过共享的 basetool 接口与 registry 装配：
- 基础层（basetool_core）定义 BaseTool 接口、元数据与跨包上下文键，是所有工具实现的契约。
- 横切层（decorators）基于 chain.Wrap 提供超时、审计、限流、指标、租户绑定、审查等装饰器，被各具体工具组合使用。
- 能力层（query_tools / query_resources / host_system_tools / topology_incident_tools / skill_mcp_bridges）各自实现一组 BaseTool，分别面向遥测查询、资源查询、主机操作、拓扑故障以及 Skill/MCP 桥接。
- 装配层（registry_and_toolbag）集中注册所有工具，并按阈值延迟加载 JSON Schema，供上层 AIOps Agent 消费。
子模块之间禁止直接互相 import，仅通过 basetool 接口与 registry 解耦；装饰器链在注册时统一注入，确保执行顺序一致。
