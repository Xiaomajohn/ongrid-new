本模块是 tools 包下的只读查询工具实现，每个文件对应一个独立工具：
- 每个工具以 `ToolName*` 常量暴露稳定的 wire name（LLM 侧看到的名称），并以 `Query*Description` 作为提示词描述；
- 通过 `json.RawMessage` 声明 JSON Schema（`Query*Schema`），并配套 Go 结构体 `Query*Args` 做反序列化与默认值/上限校验；
- 执行函数统一签名 `(r *Registry) executeQuery*(ctx, args)`，返回 `ExecuteResult{ResultJSON}`，内部对 `alertUC`、`devices`、`edges` 等依赖做 nil 检查后调用 usecase 层（`alertbiz`、`devicebiz`、`edgebiz`）；
- 由于底层 usecase 的 filter 能力有限（如 `IncidentFilter` 不支持 since_minutes、`ListRules` 仅支持 scope_type），本层在内存中完成二次过滤（时间窗口、kind/enabled/name_contains、role/status 等），并通过 `Limit` 上限 + 提前 break 控制输出大小；
- 所有对外调用的 usecase 都包裹 `context.WithTimeout`（10~15s），错误统一以 `fmt.Errorf("tool_name: ...")` 前缀包装以便定位。
依赖方向：tools → biz/usecase → model，不直接访问 DB。
