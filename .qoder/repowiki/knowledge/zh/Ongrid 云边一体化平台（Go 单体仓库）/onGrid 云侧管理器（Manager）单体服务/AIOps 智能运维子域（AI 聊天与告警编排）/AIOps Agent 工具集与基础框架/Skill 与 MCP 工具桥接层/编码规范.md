- 对外暴露的 wire name 一律通过前缀+分段清洗函数生成（如 `mcp__` + `sanitizeMCPSeg`），确保 LLM 路由与去重稳定。
- 对外部不可信能力默认走「提议-审批」异步路径，仅在显式 trusted 标记下才允许同步直调，并在缺少依赖时返回明确错误。
- JSON Schema 构建优先使用 `BuildSchema` + `RawSchemaProvider` 保留手写 schema，避免被 ParamSchema 降级丢失数组/嵌套结构。
- 面向 LLM 的错误输出统一包裹为 `{result, error}` 结构化 envelope，保证模型始终看到一致的结构而非裸字符串。
