本模块是 AI Tools 层的「叶」契约包，被上层 decorator 链与下层具体 tool 实现共同依赖，避免 import 环。
- 核心契约：`BaseTool` 接口 + `ToolInfo` 元数据（Name/Description/WhenToUse/Parameters/Class/Origin），以及 `InvokeOption` / `Resolved` 功能选项模式，用于在 `InvokableRun` 中透传 tenant/userID/deviceID/userText 等每调用上下文；`Origin*` 常量区分 builtin/mcp/skill 来源，`IsDynamic()` 辅助路由决策。
- 上下文传播子文件：每个 ctx 值通过独立文件（`session.go`、`artifact_source.go`、`host_write.go`、`filtered_tools.go`、`locale.go`）以私有 key 类型 + `WithXxx`/`XxxFromContext` 对暴露，遵循「空值即 no-op」的安全默认策略，使 chatruntime（设置方）与 tools/*（读取方）仅依赖 basetool 而不互相导入。
- 辅助设施：`bound_credentials.go` 提供凭据绑定、`llm_choice.go` 承载 LLM 选择偏好、`wire_test_helper.go` 为 wire 注入提供测试桩，均保持纯函数式、无外部副作用。
