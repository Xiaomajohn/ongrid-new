本包属于 tools 子目录，每个文件定义一个独立的 Tool（ToolName + Description + JSON Schema + Args 结构体 + executeXxx 方法），由上层 Registry 注册并通过统一的 ExecuteResult 返回 JSON 给 LLM。

- correlate_incident.go：核心编排器。以 `correlateIncidentBundle` 作为稳定 wire 输出，依次从四个数据源拉取并裁剪到 100KB 以内（先砍日志再砍 trace，最后丢弃 metric values）：PromQL 通过 `promExprForIncident` + `metricExprFor` 把 alert rule 的 closed-set 指标名翻译为 PromQL；Loki 用正则过滤 error/panic/oom/fatal/fail；Tempo 基于 service 标签搜索；edge 快照还叠加了 24h 告警 flap 计数。所有上游调用都带独立超时，失败只记入 bundle.Skipped 而非中断整个流程。
- get_topology.go：无参工具，汇总 manager_version、配置的后端 URL、edge 在线数、enabled rule 数、channel_count（通过回调注入）。
- rank_edges.go：将 cpu/mem/disk/load/composite 五个 closed-set 指标映射为 PromQL topk/bottomk 查询，并用一次 edges.List(500) 批量补全 edge_name。

依赖方向单向向外：仅依赖 alertbiz/alertmodel、edge biz/model、pkg/promquery/logquery/tracequery、devicemodel；反向不引入任何 manager 顶层包，避免循环。
