本模块由三个文件组成两条并行但互补的工具管线：
- registry.go 实现基于 name→executor 映射的 Registry：以 Caller/edge/device/alert/prom/log/trace/knowledge/topology/spawner/audit/plugin/config/page/im/pageStore 等接口作为外部依赖边界，NewRegistry 根据可选依赖是否非 nil 条件性注册 query_promql/query_logql/query_traceql/rank_edges/find_outlier_edges/correlate_incident 等工具；Register/Schemas()/Invoke 暴露 llm.ToolSchema 形状给上层 ChatModel。
- toolbag.go 在 basetool.BaseTool 之上实现两级分桶（core vs specialty）的 ToolBag：当工具总数超过阈值（默认 30，可通过 ONGRID_TOOLBAG_DEFERRAL_THRESHOLD 调整）时，specialty 工具被 redactedTool 包装，Info() 返回空 Parameters 并提示通过 ToolSearch 拉取完整 schema，从而控制 LLM prompt 预算；SchemasForLLM/AllTools/DeferredTools/WithExtra/Append 构成对外 API。
- config_tools.go 实现 draft_config_change / apply_config_change 两个写路径工具，通过 ConfigManager 接口与 alertdraft 协作，采用 draft→hash 校验 + admin+confirmed 门控确保幂等与安全，并在 marshalConfigToolResult 中递归 scrub 敏感字段（secret/password/token 等）。
依赖方向：本包向上暴露 Registry 与 ToolBag 供 graph 节点使用，向下通过 interface 解耦 edgebiz/devicebiz/topologybiz/alertdraft 及 frontierbound Caller，避免直接持有 SDK 类型。
