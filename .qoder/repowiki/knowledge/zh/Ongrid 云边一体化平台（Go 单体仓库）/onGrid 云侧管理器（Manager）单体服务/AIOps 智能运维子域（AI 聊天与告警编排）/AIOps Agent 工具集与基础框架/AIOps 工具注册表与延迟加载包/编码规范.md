- 对外部依赖一律声明为窄接口（Caller/PromQuerier/LogQuerier/TraceQuerier/AlertUsecase/KnowledgeSearcher/TopologyInfo/WorkerSpawner/SubagentRegistry/AuditLister/PluginConfigLister/ConfigManager/CloudBashProposer/IMSender/PageStore），构造后通过 SetXxx 注入，使 NewRegistry 签名稳定且测试可伪造。
- 工具注册采用“名称常量 + 描述常量 + JSON Schema 常量 + Execute 闭包”四件套形式，通过 r.Register(Tool{Name, Description, Schema, Execute}) 集中声明，便于条件注册与批量枚举。
- 可选能力统一以 nil-safe 方式处理：当对应依赖为 nil 时该工具不注册（如 promQuery/logQuery/traceQuery/alertUC/knowledge/topologyGraph/spawner 等），保证最小部署也能启动。
- 写操作工具强制走 draft→apply 两阶段：draft 生成 payload 与 sha256 hash，apply 必须携带 confirmed=true、admin/superuser 角色、匹配的 draft_hash 才能执行，并通过 normalizeConfigDomain/normalizeConfigCreateAction 做白名单归一化。
- 返回给 LLM 的配置结果统一经 marshalConfigToolResult → scrubConfigToolSecrets 递归清洗，对 secret/app_secret/verify_token/encrypt_key/token/password/api_key 等键值替换为 "******"。
