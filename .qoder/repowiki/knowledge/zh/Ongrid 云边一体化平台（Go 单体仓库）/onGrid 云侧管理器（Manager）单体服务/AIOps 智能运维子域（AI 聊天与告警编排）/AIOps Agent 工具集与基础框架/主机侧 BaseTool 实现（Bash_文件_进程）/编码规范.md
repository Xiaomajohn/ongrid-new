- 每个 BaseTool 暴露一组命名常量：`ToolNameXxx`（稳定 wire 名）、`XxxDescription`（一行说明）、`xxxWhenToUse`（路由提示）、`XxxSchema`（JSON Schema），并在 `Info()` 中以 Class="read" 返回。
- 参数先反序列化为带 json tag 的 struct，再对必填字段和范围做显式校验（如 device_id > 0、paths 长度 1..16、top_n/min_size_bytes 上下界截断），错误一律以 `fmt.Errorf("toolName: ...", err)` 前缀包装。
- 通过 `deviceResolverAdapter{inner: NewDeviceResolver(d, e)}` 把 `DeviceResolver` 适配到本地 `hostFilesDeviceResolver.LookupHostEdge` 接口，使测试可注入 fake 而生产走真实 junction。
- 对 edge 的每次 tunnel 调用都包裹 `context.WithTimeout`（per-call timeout），并在 envelope 中统计 `success_count` / `error_count`，让 LLM 能判断是否需要重试失败条目。
- batch 类工具使用 `runBatch(ctx, ids, fn)` 并发派发，单个 device 的错误折叠进结果项的 `Error` 字段而不中断整个批次。
