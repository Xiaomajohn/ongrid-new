- 每个工具以 `ToolName*` + `Query*Description` + `Query*Schema` + `Query*Args` + `executeQuery*` 五件套形式自包含定义，对外仅暴露 const 和 schema，执行逻辑对 Registry 隐藏。
- 所有外部 I/O 调用使用 `context.WithTimeout(ctx, query*CallTimeout)` 包裹，超时统一设为 30s，并在 defer 中 cancel。
- 错误信息采用 `"query_<tool>: <阶段>: %w"` 前缀模式（bad args / required / parse / dispatch / marshal），保持跨工具一致的可观测性。
- 通过本地声明的 `*Querier` 接口（PromQuerier / LogQuerier / TraceQuerier）隔离第三方 pkg，使 Registry 字段类型与具体客户端解耦，便于单元测试注入 mock。
