本模块是 aiops tools 层中面向 host 的三个 BaseTool 实现集合，统一通过 `tunnel.Caller` 反向调用 edge agent：
- `bash_basetool.go` 实现 `host_bash`，采用 batch-first 语义：一次调用携带单条 `cmd` + 最多 16 个 `device_ids[]`，内部用 `runBatch` 并发派发，每个 device 独立走 cmdpolicy 沙箱校验；响应以 `BashBatchResponse` 信封回传，`cmd` 只出现一次以节省 token。
- `host_files_basetool.go` 集中实现 `host_find_large_files`、`host_du_summary`、`host_stat_file` 三个工具，共享 `hostFilesDeviceResolver` 接口与 `deviceResolverAdapter`（桥接 `DeviceResolver.ResolveEdgeID`）、`dispatchEdgeCall` 超时封装以及 `validateBatchPaths` 批量校验；`du_summary` 额外在 manager 端计算 `coverage`（扫描字节 vs root-fs used），当解释度 <80% 时向 LLM 注入 `INCOMPLETE` hint 强制继续下钻。
- `host_processes.go` 仍沿用旧版 `Registry.executeGetProcessList` 风格（基于 `edge_name` 解析而非 device_id），作为遗留兼容路径保留。
依赖方向：本模块 → `basetool.ToolInfo` / `Caller` / `DeviceResolver` → `internal/pkg/tunnel`（定义 RPC method 常量与请求/响应结构体）→ `devicebiz.Usecase` + `edgebiz.Usecase`（仅用于构造 resolver）。所有写操作被标记为 Class="read"，由 v1 cmdpolicy 在 edge 侧拒绝写入。
