- 构造器统一采用 `New(..., cfg Config)` 形式，在构造函数内对零值字段填充默认值（如 MaxIterations=30、Temperature=0.1、Workers=3、QueueDepth=100），使调用方可传入空结构体获得安全行为。
- 对外依赖一律声明为窄 interface（如 `MentionResolver`、`ToolInvoker`、`EventWriter`、`logQuerier`），避免直接 import 重型包，方便测试注入 fake 且降低耦合面。
- 可选依赖允许 nil 接收者：当 llmClient/tools/events 任一为 nil 时，服务退化为 no-op（不抛错、不阻塞），由上层 wiring 阶段决定是否启用。
- 错误处理遵循“失败即降级”原则：单个数据源查询失败或解析失败不会中断整体流程，而是记录 warning 后跳过该分支，保证 UI 响应性。
- JSON 输出统一使用 `truncateJSON` / `capUserMessage` 截断超大 payload 并在尾部追加 `...(truncated)` 标记，区分人类可读显示与可重放内容。
