本包是 `internal/manager/biz/aiops` 中定义的领域接口（如 `SessionRepo`）的 GORM/SQLite 具体绑定，位于 data 层，依赖方向单向指向 biz 接口与 model 实体。
- 仓储对象：`SessionRepo`（会话/消息/工具调用）、`MutatingProposalRepo`（变更审计提案）、`UserAgentRepo`（用户定义 persona），均通过 `NewXxxRepo(db *gorm.DB)` 构造并持有同一个连接池。
- 表迁移集中在 `migrate.go`，通过 `db.AutoMigrate` 注册 `model.Session / Message / ToolCall / MutatingProposal / UserAgent` 五张表；CHECK 约束由 model tag 同时作用于 MySQL 与 SQLite。
- 复合查询采用 GORM 链式构建（`Where / Order / Limit / Offset`），聚合类统计（`SumTokensSince`）回退到 Raw SQL 以便审计；`ListMessages` 对 assistant 消息批量 JOIN 填充 `ToolCalls`，避免 N+1 且保证 tool_calls 严格跟随 assistant turn。
- 删除走显式事务，按 `tool_calls → messages → sessions` 顺序级联，因为 schema 未声明外键。
- 错误统一经 `github.com/ongridio/ongrid/internal/pkg/errs` 映射为 `ErrNotFound / ErrInvalid`，并通过 `var _ biz.SessionRepo = (*SessionRepo)(nil)` 在编译期校验接口实现。
