模块分为两层：
- 顶层 graph（types.go / react.go / tool_adapter.go）：对外暴露 `BuildReActGraph(model, tools, cfg)` 返回 `compose.Runnable[*Input, *Output]`；内部用 eino 的 `react.NewAgent` 生成标准 ReAct 子图（ChatModel ↔ Branch ↔ ToolsNode），外层再包裹两个 lambda 节点完成输入拼装与输出投影，节点名常量 `MessageAssembler` / `ReActSubgraph` / `OutputProjector` 供回调过滤。
- 工具适配层（tool_adapter.go）：`einoToolAdapter` 把仓库自有的 `basetool.BaseTool` 桥接到 eino `InvokableTool`，并在 `InvokableRun` 中实现 per-run 相同参数缓存（仅 Class=="read"）、每工具调用上限（默认 8，`draft_config_change`=1、`list_metric_catalog`=2）、以及 `draft_config_change` 对 `list_metric_catalog` 的前置依赖门控；Go 错误被重写成 JSON envelope 作为工具结果返回，避免中断整个图。
- 回调横切层（callbacks/）：每个文件一个 `callbacks.Handler`（persistence / sse / audit / metrics / alert_draft_guard），由 `chain.go` 的 `NewDefaultHandlers(deps Deps)` 按固定顺序组装，通过 `assistantIDRelay` 在 PersistenceHandler 与 SSEHandler 之间传递刚写入的 assistant row id；`FinalizeBatches` 在请求结束时 flush 未完成的 tool 批处理。PersistenceHandler 维护 `currentBatch` 做 autoheal——当 eino ToolsNode 并行工具 OnEnd 丢失时，下一轮 ChatModel.OnStart 自动补写 stub role=tool 行，保证历史回放信封结构完整。
- 依赖方向：graph → basetool（仅接口）；callbacks → biz.SessionRepo + model/aiops（写库）+ slog/prometheus；graph 不直接依赖数据库或 HTTP，全部通过回调链和 WithInvokeOpts 透传。
