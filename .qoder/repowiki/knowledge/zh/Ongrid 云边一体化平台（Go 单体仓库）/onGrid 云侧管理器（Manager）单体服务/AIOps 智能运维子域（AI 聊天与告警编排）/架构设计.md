本模块按 internal/manager/{biz,server,data}/aiops 三层切分：
- biz/aiops 为纯业务层，chatruntime 基于 cloudwego/eino 的 react 图驱动多 Agent 协作，graph/callbacks 注入 SSE/审计/指标/持久化等横切逻辑；tools_and_basetool 通过 registry + ToolBag 将查询/主机/拓扑/Skill/MCP 等工具统一暴露给 Agent；alert_pipeline 负责自然语言→告警规则的编译校验；lightweight_subsystems 提供 tool-calling Agent 主循环、@提及搜索与工具回放。
- server/aiops 仅暴露 chi 路由与 SSE 流式接口，把 HTTP 请求映射到 biz 层的 chatruntime/repo 调用。
- data/aiops/store 以 GORM+SQLite 实现会话、消息、变更提案等实体 CRUD，被 graph/callbacks/persistence 与 alertdraft/draft_store_memory 共享。
跨层契约由 biz/aiops/repo.go 定义的仓储接口与 tools/basetool 的基类/装饰器约定维系，server 层不直接依赖 data 层，所有 I/O 经 repo 抽象。
