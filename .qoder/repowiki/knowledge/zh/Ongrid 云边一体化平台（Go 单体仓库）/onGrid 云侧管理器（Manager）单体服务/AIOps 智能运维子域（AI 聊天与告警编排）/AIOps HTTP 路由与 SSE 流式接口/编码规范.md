- HTTP handler 统一以 `callerFromCtx(r.Context())` 从 tenantctx 提取 Caller，失败直接返回 401，避免在每个路由重复鉴权逻辑。
- 对外部可选能力通过接口字段 + `SetXxx` 注入，nil 时端点返回空结果或 503 而非 panic，保证不同构建变体共存。
- 错误处理走 `writeErr` + `errs.HTTPStatus` + `errCode` 映射，将内部 error 枚举转为前端可读的 code 字符串（如 `budget-exceeded`、`edge-offline`）。
- 请求 DTO 与响应 DTO 在文件顶部集中声明并使用 json tag，再通过独立的 `toXxxDTO` 函数与 domain 模型互转，保持 handler 主体只负责编排。
- SSE 事件通过 `eventName`/`eventPayload` 两个 switch 把 `agent.EventType` 映射为 wire 帧，新增事件类型只需改这两处。
