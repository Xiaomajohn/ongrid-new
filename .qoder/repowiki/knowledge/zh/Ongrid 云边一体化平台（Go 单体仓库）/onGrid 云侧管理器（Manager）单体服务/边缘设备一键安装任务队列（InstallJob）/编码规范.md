- 对外契约使用 interface（Repo、Usecase、EdgeIssuer、Installer、EdgePresence），具体实现通过 NewXxx 工厂返回，避免上层直接依赖 gorm 或第三方包。
- 可选的外部依赖字段允许 nil，Execute 中遇到 nil 时打 WARN 日志并走 no-op 分支，使单元测试和 partial wiring 无需注入所有依赖。
- 错误统一经 `internal/pkg/errs` 包装并通过 `errs.HTTPStatus` 映射到 HTTP 状态码，handler 侧用统一的 `writeErr` 输出 `{error, code}` JSON。
- 敏感凭据（secret_key/password）仅在 Worker 生命周期内驻留于行快照，终态前必须调用 `ClearCredentialSnap` 清空，写入日志前通过 `redactSecretKey` 脱敏。
- 数据 schema 实体集中在 data 包，biz 层通过 type alias 转引同一类型，确保 gorm 读写与业务判定的类型 identity 一致。
