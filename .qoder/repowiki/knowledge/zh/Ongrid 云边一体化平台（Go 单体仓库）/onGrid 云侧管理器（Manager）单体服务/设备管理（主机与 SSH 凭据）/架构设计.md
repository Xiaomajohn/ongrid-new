本模块按经典的三层划分组织：
- `server/device/`：基于 go-chi/v5 的 HTTP 路由层，暴露 `/v1/devices` 及子资源（roles、ssh-credentials、restore、edges），通过 `requireAdmin` 中间件做租户上下文 + admin 角色校验，所有请求体/响应体以本地 DTO（`createReq`、`deviceItem` 等）承载，仅映射到 biz 层。
- `biz/device/`：领域用例层，定义 `Repo` 与 `EdgeDeviceRepo` 两个接口，封装输入校验（如 SSH auth_kind/password/key 互斥）、fingerprint 派生（`manual:` 前缀 + UUID）、软删除/硬删除分支、以及跨实体的 presence 协调（`ReconcilePresence`、`PingReachable`）。Usecase 持有可选的 `links EdgeDeviceRepo`，未注入时退化返回 `ErrNotWiredYet`，使边缘注册路径与纯主机路径可独立组装。
- `data/device/store/`：GORM 实现，同时支持 SQLite 与 MySQL；`migrate.go` 在启动时执行 AutoMigrate 并运行从旧 `edges` 表到 `devices` + `edge_devices` 的幂等 backfill（保留原 id 以保持 Prometheus 标签兼容），`sql/migration_*.sql` 存放增量 DDL（SSH 凭据列、安装任务表）。
依赖方向严格单向：server → biz → data/store，且 server 对 edge 的在线状态查询通过 `EdgeLookup` 窄接口反向注入，避免循环导入。
