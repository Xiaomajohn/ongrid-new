- 对外暴露的存储依赖以 interface 形式注入（`Repo`、`Generator`、`IDGen`、`readyChecker`），构造函数接受 nil 时使用 no-op 或 panic 明确约束，便于测试替换与渐进式 PR 落地。
- 数据库唯一冲突统一通过 `isDuplicateKey` 检测 MySQL ER_DUP_ENTRY 与 SQLite UNIQUE constraint failed 字符串，并映射为 `errs.ErrConflict`，由上层用例视为幂等跳过而非硬错误。
- 时间与时区处理遵循“输入校验 + UTC 存储”模式：`loadLocation` 空串回退 UTC，非法 tz 包装 `errs.ErrInvalid`；`Scheduler` 内部统一用 `now.UTC()` 驱动 tick，避免 goroutine 间时区漂移。
- HTTP handler 一律从 `tenantctx.From(r.Context())` 取租户上下文，写路由经 `requireWriter` 中间件拒绝 `viewer` 角色，错误通过 `writeErr` 转为标准 `errs.*` 响应码。
- 业务错误通过 `errors.Join(errs.ErrXxx, err)` 组合语义错误码与底层原因，保持可断言性与可读性并存。
