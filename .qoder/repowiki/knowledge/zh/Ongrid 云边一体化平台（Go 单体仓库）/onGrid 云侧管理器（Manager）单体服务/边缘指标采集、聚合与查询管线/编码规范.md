- 对外暴露的接口均声明为窄 interface（如 `MetricService`、`Writer`/`Reader`、`Writer` in promwrite），由具体 struct 通过结构体匹配满足，测试侧直接注入 fake。
- HTTP handler 统一使用 `parseID`/`parseTime` 解析参数并以 `errs.ErrInvalid`/`ErrNotFound` 等标准错误包装后走 `writeErr`，错误码映射集中在 `errCode` switch。
- 响应字段对可空值一律使用指针（`*float64`/`*uint64`），缺失 bucket 序列化为 JSON null，使前端 recharts 能在断点处断开连线而非桥接为 0。
- 批量写入采用固定常量 `createInBatchesSize = 500` 分片，并在方法入口对空切片短路返回，避免无意义 DB 往返。
- 错误分类保持低基数：`classifyReason` 将 flush 失败归入 `ctx_cancel`/`write_error`/`unknown` 三类，避免把 err.Error() 直接当 label。
