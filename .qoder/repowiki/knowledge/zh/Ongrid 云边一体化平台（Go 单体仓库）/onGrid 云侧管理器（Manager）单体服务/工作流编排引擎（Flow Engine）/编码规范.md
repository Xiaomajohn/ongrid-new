- 节点行为通过 `NodeSpec` 注册到全局 registry，引擎以 `LookupNode` 查找而非字符串 switch，新增节点只需 `RegisterNode` 一行。
- 外部能力（Agent/LLM/Tool/Notify）统一通过 `Executors` 缝合面注入，nil 时退化出明确错误，使引擎可在零依赖下单测。
- 对共享 `RunContext` 的写入集中在 `runState.mu` 保护段内，executor 返回 `NodeResult.Vars` 让引擎在锁内合并，避免并发竞态。
- HTTP handler 一律使用 `writeErr`/`errCode` 将 `errs.*` 错误映射为 `{error, code}` JSON，读取路径放行 viewer，写入路径用 `requireWriter` 拦截。
- 运行时资源（cron tick、run prune）通过 goroutine + context 控制生命周期，重启后状态通过 `SweepStaleRunning` 自愈。
