- 对外依赖一律声明为窄接口（如 `Repo`、`Authenticator`、`GrafanaService`、`PromQuerier`、`URLProbe`），由 cmd/ongrid 组装时注入，避免 handler/usecase 直接 import 具体实现。
- 构造器接受 `log *slog.Logger` 且允许 nil，内部用 `if log == nil { log = slog.Default() }` 回退，使单元测试无需传入 logger。
- 可选能力通过 nil 字段表达而非 panic：当 prom/loki/tempo/websearch probe 未注入时对应 `/test` 端点返回 503 并带 `*-disabled` code；frontierbound 的 `NewDisabled` 让所有 outbound 调用返回 `ErrDisabled`。
- handler 统一通过 `writeJSON`/`writeErr` 输出 `{error, code}` JSON，并用 `errors.Is(err, errs.Err*)` 映射 HTTP 状态码，禁止在 handler 里直接写 status。
- 审计事件采用「显式标注」模式：`AuditMiddleware` 只持久化被 handler 调用 `SetAuditEvent` 标注的请求，未标注的请求静默跳过，避免产生无意义的 http_* 行。
- biz 层 write 路径失败一律只 warn 日志不向上抛错（audit `Emit`、approval `SetResult` 失败），保证核心业务流程不被辅助功能阻塞。
