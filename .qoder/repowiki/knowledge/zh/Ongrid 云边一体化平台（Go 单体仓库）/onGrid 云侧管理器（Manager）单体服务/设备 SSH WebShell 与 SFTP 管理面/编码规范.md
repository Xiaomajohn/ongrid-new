- HTTP handler 与 biz 层之间通过小接口（如 `DevicesshService`、`SFTPService`、`Streamer`、`Recorder`）解耦，构造期注入，便于测试替换与 A3/A5 渐进落地。
- 当 biz 与 server 需要共享同构结构体但又要避免 import cycle 时，采用“平行类型”（`biz/devicessh.ShellOpts`/`ShellHandle` 与 `server/devicessh` 同名结构一一对应），由 main 组装层做字段映射。
- 错误统一使用 `github.com/ongridio/ongrid/internal/pkg/errs` 中的哨兵（`ErrNotFound`/`ErrUnauthorized`/`ErrInvalid`/`ErrNotWiredYet`/`ErrEdgeOffline`），并由 `errs.HTTPStatus` 映射为 HTTP 状态码，handler 侧用 `errCode` switch 返回前端可读 code。
- WebSocket 交互遵循固定握手序列：upgrade 后 10s 内必须收到 type="open" 文本帧，随后以 type="ready" 确认，二进制帧承载 stdin/stdout，文本帧承载 resize/close 控制。
- 并发安全通过 `sync.RWMutex` 保护活跃会话 map（`biz/webshell.Router.sinks/meta`），配合 `atomic.Uint64` 统计每 session 的 stdout 字节数，供审计与列表接口读取。
