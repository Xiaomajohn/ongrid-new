模块按 clean-architecture 三层切分：
- `biz/edge`：领域用例层，核心是 `Usecase`（`usecase.go`），负责 Edge 生命周期（Create/List/Delete/RotateSecret）、Tunnel 回调（HandleRegister/HandleHeartbeat/HandleOffline）、设备指纹 upsert 与拓扑镜像；通过 `Repo`、`devicebiz.Repo`、`NodeMirror`、`PluginConfigSeeder` 等接口解耦外部依赖，避免循环导入。
- `server/edge` + `server/edgeauth`：HTTP 适配层。`server/edge/http.go` 基于 chi 暴露 `/v1/edges*` 管理 API，并通过 `AuthzMW` 注入 casbin 或回退到 `requireAdmin`；`server/edgeauth/http.go` 暴露 `/internal/auth/dataplane-verify` 供 nginx `auth_request` 调用，复用同一套 AccessKey/SecretKey 校验逻辑。
- `data/edge/store`：GORM+SQLite 持久化实现，提供 `NewBizRepo(db)` 构造器返回 `biz.Repo` 接口，由 `cmd/ongrid` 在装配期绑定。
依赖方向严格单向：server → biz → data/store；biz 不直接依赖 server 或 data，仅通过接口反向注入（如 `SetNodeMirror`、`SetPluginSeeder`）。
