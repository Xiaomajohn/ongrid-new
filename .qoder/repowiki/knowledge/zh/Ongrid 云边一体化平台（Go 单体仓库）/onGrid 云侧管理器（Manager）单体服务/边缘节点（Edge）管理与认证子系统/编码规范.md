- 对外部依赖一律以 interface 形式注入（Repo、AuthzMW、PackageResolver、PluginConfigSeeder、NodeMirror），构造函数接收后通过 SetXxx 方法可选装配，零值 Usecase/Handler 可安全存在。
- 写操作权限统一走 `writeMW(obj)/deleteMW(obj)` 中间件，优先使用 casbin `Require(obj, act)`，未装配时回退到 `requireAdmin` 检查 tenantctx.Role == "admin"。
- 错误响应统一经 `writeErr` 包装为 `{error, code}` JSON，`errCode` 将 sentinel error 映射为 kebab-case 字符串码，HTTP 状态由 `errs.HTTPStatus` 决定。
- 可选参数采用 func-options 模式（`CreateOption` / `WithDeviceID` / `WithTaskName`），零值视为 no-op，保持向后兼容的单参调用路径。
- Best-effort 副作用（拓扑镜像、设备 last_seen 同步、默认插件种子）失败只记录 Warn 日志并继续执行主流程，不阻断 Edge 创建/心跳。
