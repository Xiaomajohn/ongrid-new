本模块是 onGrid 的「云侧管理器」单体：cmd/ongrid/main.go 作为唯一入口，按固定顺序初始化 DB、Tracing、LLM、Edge 连接池与 Settings，随后在 internal/manager/server 下为每个业务域注册 /v1/* HTTP 路由；各域遵循 biz → data/store → model 三层拆分，biz 层通过 data/store 接口访问 GORM/SQLite，model 层由所有 store 共享。

跨域协作方式：
- shared_infra 提供中间件（审计、指标）、审批工作流、Grafana 自动配置、Frontier 边管客户端与 AI Ops 告警规则适配，被 alert、aiops、edge_management、monitoring 等多个子域直接依赖。
- settings 作为全局运行时配置源，被 aiops、imbridge、marketplace、metric_pipeline、reporting 等消费。
- imbridge 将飞书/Telegram/Slack 入站消息归一化后写入 aiops 的 chat_session，形成 IM→AI 对话链路。
- installjob 与 edge_management 配合完成 agent 一键上线后的插件配置下发。
- flow_engine 可调用 skill_catalog、secret_vault、mcp_integration 等能力节点构成 DAG。
- metric_pipeline 与 monitoring 共用 promwrite ingester，前者写 ClickHouse、后者暴露查询代理。

隔离机制：每个子域独立目录（biz/data/store/model/server），仅通过 Go 包 import 显式耦合；HTTP 路由在 server 层集中注册，避免 biz 层直接依赖 net/http。
