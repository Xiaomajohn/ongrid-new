- 跨层依赖通过小接口隔离：handler 依赖 `Service` 接口，biz 依赖 `Repo` 与 `SecretResolver` 接口，构造时以构造函数注入而非全局变量。
- 错误统一使用 `internal/pkg/errs` 中的哨兵错误（`ErrInvalid`/`ErrNotFound`/`ErrConflict`/`ErrUnauthorized`/`ErrForbidden`），并通过 `fmt.Errorf("%w: ...", err)` 包裹后再用 `errors.Is` 在 mapper 中匹配。
- HTTP handler 遵循固定模板：先 `requireAdmin` 鉴权，再 `parseID` 解析路径参数，然后 `json.NewDecoder(MaxBytesReader(..., 64<<10)).Decode` 限制请求体大小，最后 `writeJSON`/`writeErr` 统一响应。
- 可编辑字段与只读字段分离：API 层使用独立的 `serverInput` struct 接收输入，再通过 `toModel()` 映射到 `model.Server`，status/tools_cache/timestamps 等由 probe 路径单独写入。
- 数据库操作统一走 `r.db.WithContext(ctx).Model(&model.Server{}).Where("id = ?", id).Updates(...)` 模式，并对 `RowsAffected == 0` 的情况返回 `errs.ErrNotFound`。
