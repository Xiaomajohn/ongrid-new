- 对外依赖一律声明为窄 interface（如 `EdgeCaller`、`AuditSink`、`Service`），构造时注入，使 HTTP 层与 biz 层均可被测试替换。
- 错误使用 `github.com/ongridio/ongrid/internal/pkg/errs` 中的 `ErrUnauthorized/Forbidden/NotFound/Invalid` 常量，并通过 `fmt.Errorf("%w: ...", errs.ErrX)`` 包装后返回，HTTP 层用 `errs.HTTPStatus` 映射状态码。
- 鉴权策略集中在 `authorize(class, role)` 单函数中，依据 skill 的 `Class`（safe/mutating/dangerous）× 调用者角色进行决策，不在各 handler 重复判断。
- 审计记录采用 best-effort 模式：`AuditSink.Record` 失败仅 slog.Warn 并继续返回成功结果，确保 DB 抖动不影响业务。
