- HTTP 处理器通过 `requireAdmin` 从 `tenantctx` 提取上下文并校验角色，非 admin 一律返回 `errs.ErrForbidden`。
- 业务层对敏感字段采用「写入时 seal、读取时 unseal」策略，API 响应仅暴露字段名集合（`FieldKeys`），从不序列化明文值。
- 错误处理统一使用 `errs.Err*` 哨兵配合 `fmt.Errorf("%w: ...")` 包装，HTTP 层由 `errCode`/`errSlug` 双函数将哨兵映射为 HTTP 状态码与 slug。
- 凭据类型通过包级 `init()` + `registerCredType` 注册到全局 map，未知类型回退到 `custom`，保证向后兼容。
- 数据层方法以 `WithContext(ctx)` 传递上下文，并通过 `RowsAffected == 0` 或 `gorm.ErrRecordNotFound` 转换为 `errs.ErrNotFound`。
