模块按三层切分：
- `server/topology`：基于 chi/v5 的 HTTP 路由层，定义 `/v1/topology/{nodes,relations,relation-types,node-types}` 全部 REST 端点，通过 `requireAdmin` 中间件保护写操作，仅做参数解析、DTO 编解码与鉴权转发。
- `biz/topology`：业务门面 `Usecase`，聚合四个 repo 接口（NodeRepo / RelationRepo / RelationTypeRepo / NodeTypeRepo），集中实现字段校验（必填、JSON 合法性）、内置类型保护（拒绝覆盖 Builtin=true 的行）、以及 `EnsureNodeForDevice` 这种跨域镜像逻辑；repo 指针允许 nil，调用时统一返回 `ErrNotWiredYet` 以支持启动期降级。
- `data/topology/store`：GORM 实现的四个 repo，配合 `migrate.go` 在启动时执行 AutoMigrate、seed 内置 RelationType/NodeType 行，并通过原始 SQL 扫描 `devices` 表把历史设备回填到拓扑节点（避免引入 device 模型包造成循环依赖）。

依赖方向严格单向：`server → biz → data/store`，biz 层只依赖 `model/topology` 和 `pkg/errs`，不感知 HTTP 或 GORM。
