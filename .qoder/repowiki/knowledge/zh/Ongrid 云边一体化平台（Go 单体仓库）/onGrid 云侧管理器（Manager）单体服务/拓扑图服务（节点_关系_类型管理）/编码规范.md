- HTTP handler 对写端点统一包裹 `requireAdmin` 中间件，读端点仅检查 `tenantctx.From` 是否存在，角色判断集中在一个中间件而非每个 handler 内重复。
- 所有 JSON 自由字段（props_jsonb）在入参侧用 `json.Valid` 校验、出参侧经 `encodeProps`/`decodeProps` 双向转换，空串等价于 nil 以便 `omitempty` 省略。
- 业务方法开头对注入的 repo 字段做 nil 检查并返回 `errs.ErrNotWiredYet`，使未连接存储时的启动路径可优雅降级。
- operator 注册类接口（RegisterRelationType / RegisterNodeType）一律先查库确认目标行是否 builtin，若是则返回 `ErrConflict`，builtin 数据由 migrator 独占。
- Delete 类接口在删除前通过 CountRelationsByType / CountNodesByType 检查下游引用，防止产生孤儿外键，错误同样包装为 `ErrConflict`。
- GORM repo 实现统一使用 `WithContext(ctx)` 传递上下文，并将 `gorm.ErrRecordNotFound` 转换为 `errs.ErrNotFound`，保持上层错误语义一致。
