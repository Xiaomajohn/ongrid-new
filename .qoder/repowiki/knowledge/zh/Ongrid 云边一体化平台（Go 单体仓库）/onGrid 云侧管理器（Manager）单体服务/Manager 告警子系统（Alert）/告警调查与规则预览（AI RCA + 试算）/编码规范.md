- 对外部依赖一律声明为窄接口（如 `Notifier`、`Investigator`、`WorkerSpawner`、`Repo`、`PreviewPromQuerier`），构造期通过 setter 或 `WithXxx` 注入，保持包间单向依赖且便于测试 stub。
- 可选能力以 nil-safe 字段 + 调用前空指针检查实现（`investigator`、`workflowDispatcher`、`spawner`、`summarizer`、`related`、`messages`），缺失时记录 warn 并降级而非 panic。
- 非阻塞路径（`InvestigateAsync`、`OnAlertFired`）通过 goroutine + context.WithTimeout 独立运行，绝不阻塞上游 firing 路径；超时/错误统一落库为 `skipped/failed` 状态供 UI 展示。
- 并发控制采用 buffered chan 做非阻塞计数信号量（`tryAcquireSem`/`releaseSem`），超限时直接写 `status=skipped` 行而不是排队，保证 UI 即时可见。
- 规则输入统一经 `buildRuleRow` + `buildConditionsJSON` 校验与编译，UI 友好 kind（`metric_threshold`）在此处降级为存储 kind（`metric_raw`），保证 DB 层单一形状。
- 错误码统一包裹 `github.com/ongridio/ongrid/internal/pkg/errs` 中的标准错误（`ErrInvalid`、`ErrNotFound`、`ErrConflict`、`ErrForbidden`），并通过 `%w` 包装保留原始语义。
