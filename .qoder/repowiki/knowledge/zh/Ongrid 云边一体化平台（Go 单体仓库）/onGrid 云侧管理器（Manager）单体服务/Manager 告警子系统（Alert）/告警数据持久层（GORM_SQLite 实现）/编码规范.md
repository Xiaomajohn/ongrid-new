- 所有单行读取方法在捕获 `gorm.ErrRecordNotFound` 后统一返回 `errs.ErrNotFound`，使 biz 层无需感知底层驱动差异。
- 批量更新方法通过 `res.RowsAffected == 0` 判断命中行数，未命中时同样返回 `errs.ErrNotFound`，保持写入一致性。
- 状态变更方法（incident/silence/delivery）先调用同文件 `validateXxxStatus` 白名单校验，再用 `map[string]any` 构造 `Updates`，只写显式列名的字段。
- 分页列表方法一律以 `Limit > 0` / `Offset > 0` 条件拼接，默认不加 limit，由调用方控制。
- Upsert 类操作（`UpsertChannelByName`、`UpsertBuiltinRule`）采用「先按唯一键 First，不存在则 Create，存在则 Updates」三段式模式，保证幂等且不覆盖管理员编辑。
- 迁移脚本全部标注幂等注释并通过 WHERE 条件匹配旧值才 UPDATE，确保多次启动不会重复改写。
