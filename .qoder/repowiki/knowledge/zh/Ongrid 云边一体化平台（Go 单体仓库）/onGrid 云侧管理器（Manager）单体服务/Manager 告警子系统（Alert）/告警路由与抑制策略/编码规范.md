- 对外暴露的组件均定义为小接口（如 `ChannelResolver`、`Inhibitor`），实现体通过构造函数注入依赖，便于测试中直接替换。
- 对底层仓库只声明最小必要接口（`channelLister`、`IncidentLookup`），而非复用外层 `biz.Repo`，以降低测试 stub 成本。
- 可选依赖使用函数类型（`RuleLookup`）并通过 setter（`SetRuleLookup`）装配，nil 时走降级路径，保证核心流程不中断。
- 当 DB 查询失败或无匹配结果时统一返回 synthetic 条目（ID=0、仅 Name），由上层 MaybeNotify 自行处理空 ID 场景。
