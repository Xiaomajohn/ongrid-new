模块由三个文件组成一个单 goroutine 的定时评估管线：
- `pipeline.go` 定义 `PipelineEvaluator` 核心结构体与 `Loop`/`EvaluateOnce` 调度入口，维护 `firingSnapshot`（每 rule_key → 上一 tick 已触发 dedupe key 集合）用于条件消失时的系统级自动恢复；通过 `EdgeLister`/`PromQuerier`/`LogQuerier` 三个接口注入外部依赖，并负责刷新 `device_last_seen_seconds_ago` gauge 以支撑 host 离线检测。
- `evaluators_phaseA.go` 实现基于 PromQL 的 Phase-A 规则：`metric_anomaly`（z-score/MAD 偏离基线）、`metric_forecast`（predict_linear 阈值预测）、`metric_burn_rate`（SRE Workbook 多窗口 SLI burn rate），共享 `runVectorRule` 统一走 Prom vector 解码 + RecordFiring + notify 路径，并通过 `observeEval` 打延迟直方图。
- `evaluators_phaseB.go` 实现 Phase-B 规则：`log_match`/`log_volume` 经 Loki QueryRange 近似 instant 查询，`trace_latency`/`trace_error_rate` 复用 Prom spanmetrics；统一通过 `sweepRecovery` 对比 `firingSnapshot` 做自动恢复。

依赖方向单向向外：本包仅依赖 `model/alert`、`pkg/prom`、`pkg/promquery`、`pkg/logquery`、`pkg/notify` 以及同包的 `Usecase/RulesProvider/Notifier/ChannelResolver/Inhibitor` 等接口，不反向依赖上层 usecase 或 HTTP 层。
