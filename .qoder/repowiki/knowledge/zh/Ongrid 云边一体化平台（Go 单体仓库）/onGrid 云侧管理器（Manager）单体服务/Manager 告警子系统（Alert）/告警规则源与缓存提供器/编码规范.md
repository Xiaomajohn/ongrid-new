- 每个 rule kind 采用「spec 结构体 + compileXxxRule(row) (XxxRule, error)」成对模式，统一从 r.ConditionsJSON 反序列化、校验必填字段、回填默认值后构造只读运行态结构。
- 可选字段 RunbookURL 与 LabelsJSON 的拷贝遵循同一模板：先判 nil/非空再 json.Unmarshal，避免重复分支逻辑。
- operator 合法性集中由 validHostOperator 校验，所有需要比较符的 kind（metric_forecast / log_match / trace_error_rate）复用该函数而非各自 switch。
- ScopeType 一律通过 effectiveScope(r.ScopeType, r.Kind) 获取，确保下游 evaluator 无需处理空字符串。
- 静态提供者 StaticRulesProvider 通过 NewStaticRulesProvider + WithXxxRules 函数式选项装配，测试侧可自由组合任意 kind 的子集。
