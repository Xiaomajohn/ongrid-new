- 所有入参在入口即校验空串，并以 `%w: category/key required` 形式包装 `errs.ErrInvalid` 返回，保持统一的参数校验风格。
- DB 不存在语义统一映射为 `errs.ErrNotFound`，上层用 `errors.Is(err, errs.ErrNotFound)` 区分“行缺失”和“查询失败”。
- 写操作后通过 `delete(s.cache, cacheKey(...))` 主动失效缓存项，确保并发读取能拿到最新值。
- 敏感字段在 List 响应中一律经 `maskValue` 掩码，仅在显式的 reveal 端点返回明文，且该端点强制 admin 校验。
- 解析器类组件（LLM/Telemetry/WebSearch/...）采用“env 默认值 + DB 覆盖 + 空值回退”的三段式读取模式，并在构造时注入 env 种子。
