- 每个 server 子包都暴露 `type Handler struct { svc ... }` + `NewHandler(svc)` + `(h *Handler) Register(r chi.Router)` 三件套，由上层组装器集中挂载路由。
- 需要管理员权限的 handler 通过 `requireAdmin(w,r)` 从 `tenantctx` 提取角色并返回 `ErrUnauthorized`/`ErrForbidden`，普通用户可读的端点则用 `requireUser` 或直接信任调用方已做鉴权。
- 错误响应统一封装为 `{"error": msg, "code": slug}` JSON，通过 `writeErr` + `errCode(err)` 将 errs sentinel 映射为字符串 code（unauthorized/forbidden/invalid/not-found/internal/upstream）。
- 对上游查询（PromQL/TraceQL/LogQL）一律在调用前用 `context.WithTimeout(r.Context(), 15s/30s)` 包裹，防止慢上游卡住 goroutine。
- 可选后端（Prometheus/Tempo/Loki）以指针字段注入且允许为 nil，handler 在入口处检测 nil 后返回 503 + 明确文案，避免 404 导致前端静默失败。
- 时间参数解析复用同一套 `parseTime` 模式：优先 RFC3339，再回退 unix 秒/毫秒/纳秒整数字符串，便于 curl 调试。
