- 对外错误一律包装在 `errs.ErrUnauthorized/Forbidden/NotFound/Conflict/Invalid` 上，HTTP 层通过 `errors.Is` 映射为统一的 `{error, code}` JSON 响应体。
- 所有可失败的外部 I/O（下载、git clone、文件系统操作）都遵循“创建临时 staging 子目录 → 成功后 rename 到最终路径 → defer/cleanup 清理 parent”的模式，避免残留。
- 所有用户可控的路径（pack ID、install path、uninstall target）在进入 `os.Remove/MkdirAll` 前必须经 `pathHasPrefix` 校验落在配置的 root 下，防止路径穿越。
- 配置项通过结构体 `Config` 注入（StagingDir、AllowedSources、RequireSignedSources、SignaturePinnedKey、DevMode、HTTPClient、GitCmd、Now），测试通过替换这些字段实现无网络 stub。
