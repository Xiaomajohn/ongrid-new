- 对外暴露窄接口（`RepoStore`、`QdrantClient`、`Service`、`AuthzMW`），业务逻辑通过构造器注入而非全局变量，便于测试替换。
- 错误统一使用 `errs.ErrNotFound`、`errs.ErrInvalid`、`errs.ErrNotWiredYet` 等哨兵值，handler 层再映射为 404/400/500。
- JSON 响应中 ID 字段一律使用 `json:"...,string"` 标签，防止 JS Number.MAX_SAFE_INTEGER 溢出导致后续 GET 404。
- 写入类路由通过 `writeMW("knowledge:doc")` / `deleteMW("knowledge:repo")` 等中间件包装，未配置 casbin 时回退到 passthrough 保持向后兼容。
- 对长内容采用先 DeleteByFilter 再 Upsert 的幂等重写模式（upload、sync、update 均如此），确保短文件覆盖不会遗留旧分片。
