模块按三层划分：
- `server/knowledge`（HTTP 层）：基于 chi 注册 `/v1/knowledge/*` 路由，定义窄接口 `Service`，通过可选 `AuthzMW` 注入 casbin 写权限校验，所有 handler 仅做参数解析、DTO 转换和审计事件埋点。
- `biz/knowledge`（领域用例）：核心 `Usecase` 组合 `RepoStore`（MySQL/GORM）、`QdrantClient`（向量检索）、`embedding.Embedder`（文本嵌入），负责 chunk → embed → upsert 流水线、repo 克隆/拉取、路径前缀去重、搜索过滤等；`builtin_vault.go` + `builtin_vault/builtin_vault.go` 把编译期 `go:embed` 的平台知识树当作“只读 repo”进行本地 materialize，无需网络。
- `data/knowledge/store`（持久化层）：GORM 实现 `RepoStore`，仅维护 `knowledge_repos` 与 `ssh_identities` 两张小表，文档本体全部落 qdrant（单 collection `ongrid_knowledge`），不存在双写。

依赖方向严格单向：server → biz → data/pkg(qdrantx/embedding)，biz 通过接口隔离外部系统，测试可注入 fake。SSH 身份管理复用同一 `RepoStore` 以在 sync 时获得事务局部性。
