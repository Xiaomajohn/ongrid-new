本仓库是 Go 单模块（github.com/ongridio/ongrid），所有子域共享同一 go.mod 与依赖图：
- 进程边界由 cmd/ 下的两个入口划分：cmd/ongrid 启动 manager_service 单体，cmd/ongrid-edge 启动 edge_agent；两者均 import internal/pkg 与 internal/skill 提供的共享库。
- API 契约集中在 api_protos（buf 生成 Go stub），manager 的 HTTP/gRPC 路由与 geminio 调用以此为事实来源，edge 侧通过 shared_libs 中的 Tunnel RPC 客户端消费同一 proto。
- IAM 作为独立服务运行，但通过 shared_libs 的 JWT + Casbin RBAC 中间件被 manager 复用，形成“认证在 IAM、鉴权在 manager”的跨进程协作模式。
- 构建与发布由根 Makefile 统一编排：build/test/lint/proto/migrate/docker/compose/package/patch 等 target 同时产出 ongrid、ongrid-edge、ongrid-web 镜像以及 ADR-024 的 edge upgrade bundle，禁止 CI/Dockerfile 直接调用 go build / docker build。
- 测试套件 tests/ 通过 build tag（integration/e2e）与 SKILL.md 能力声明被 manager 与 edgeagent 加载，实现端到端验证。
