本模块由多个独立子包组成，每个子包对应一个 Method* RPC，统一通过 `tunnel.Client.RegisterHandler` 在 agent 启动时注册到共享的隧道客户端上，形成「方法常量 → 包级 Register → 闭包 handler」的统一装配模式：
- `bash/`：基于 `cmdpolicy.Sandbox` + `host_files.DefaultSandboxConfig()` 路径白名单的沙箱化命令执行，支持 `/etc/ongrid-edge/bash-policy.yaml` 覆盖默认只读策略，并提供 `Unrestricted` 旁路开关。
- `host_files/`：实现 find_large_files / du_summary / stat_file 三个批量文件查询工具，使用泛型 `runBatch[T]` + `errgroup.WithContext` 并发处理最多 16 个路径，按 GOOS 分支调用 GNU/BSD find、du、df，并通过 `SandboxConfig.ValidatePath` 做路径沙箱校验。
- `restart_service/`：首个变更类技能，维护本地 systemd unit 短名 allow-list（nginx/redis/prometheus/loki/tempo/grafana/mysql/ongrid），当前以 Mocked=true 返回假成功，禁止未实现的真实 systemctl 调用。
- `webshell/`：纯 TCP 流转发器，不持有 SSH/PTY 状态；接受两种 target 格式——受限回环白名单与带 `host:` 前缀的跨主机地址，后者要求 `device_id` 与本机指纹匹配以防伪造。
- `skill/`：通用 execute_skill 分发器，从 `internal/skill` 全局注册表按 key 查找并调用 Executor。
- `service/`：get_host_load / get_process_list 等只读工具，提供带 `biz.Collector` 注入和零值 stub 两套注册入口。
依赖方向单向向外：仅依赖 `internal/pkg/tunnel`（方法常量、请求/响应结构）和各自领域包（cmdpolicy、host_files、biz、internal/skill），各子包之间互不引用，由上层 agent 组装。
