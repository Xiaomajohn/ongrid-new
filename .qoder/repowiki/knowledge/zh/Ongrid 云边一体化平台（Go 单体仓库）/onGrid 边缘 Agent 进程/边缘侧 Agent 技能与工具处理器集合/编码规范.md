- 每个子包暴露 `Register(client tunnel.Client, log *slog.Logger) error` 作为唯一装配入口，内部构造默认 SandboxConfig 并调用 `client.RegisterHandler(tunnel.MethodXxx, makeXxxHandler(...))`。
- handler 闭包统一先 `json.Unmarshal` body（空体跳过），再对必填字段做最小校验并以 `fmt.Errorf("pkg: bad req: %w", err)` 风格返回错误，便于上层统一审计。
- 对外部可配置的安全边界（路径白名单、unit 列表、loopback 目标）均提供 `DefaultSandboxConfig()` + `Validate()` + 可选覆写路径，失败时记录 warn 日志但保持 boot 继续。
- 所有涉及外部进程或网络 I/O 的 handler 都显式设置 context timeout（如 hostFilesPerPathTimeout、restartHandlerTimeout），避免单个请求永久占用 tunnel slot。
- 需要区分 Linux/Darwin 行为的代码采用 build tag 拆分文件（如 `times_linux.go`、`times_darwin.go`）或在运行时 `runtime.GOOS` 分支，而非条件编译整函数。
