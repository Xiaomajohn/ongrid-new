- 所有 cloud→edge RPC 处理器统一通过 `client.RegisterHandler(method, func(ctx, session, id, body) ([]byte, error))` 注册，并在函数体内用 `jsonDecode` 解析请求、`jsonEncode` 包装响应，错误直接返回给对端。
- 周期性任务使用 `time.NewTicker` + `select { ctx.Done(), t.C }` 模式，错误只记录日志不向上冒泡，依靠下一次 tick 重试。
- goroutine 间信号传递采用带缓冲 1 的 channel（如 `upgradeRequested`），配合非阻塞 send（`select { case ch<-...: default: }`）避免发送侧阻塞。
- 对外可插拔能力通过接口抽象（`Collector`、`tunnel.Client`），具体实现放在独立子包或外部包，biz 层只依赖接口而非具体类型。
