- 二进制策略通过 addBin 注册后，若同一 Bin 再次调用则覆盖前一条，DefaultReadOnly 利用该特性先注册基础项再追加 DeniedArgs/Matchers。
- ArgMatcher 支持 AnyFlag/Subcmd/SubcmdPath 三种子规则，空匹配器作为 catch-all 用于表达“未命中其他规则即视为某类操作”。
- 决策顺序固定为 DeniedArgs 子串黑名单 → WriteMatchers → ReadOnlyMatchers → 类默认值，mixed 类默认拒绝以保证安全。
- Sandbox.Decide 仅在 Policy.Decide 通过后才进行路径与网络主机校验，保持策略层与 I/O 层的解耦。
- 输出截断统一通过 capWriter 包装 bytes.Buffer，并在 ShellResult.Truncated 中向上游暴露是否被截断。
