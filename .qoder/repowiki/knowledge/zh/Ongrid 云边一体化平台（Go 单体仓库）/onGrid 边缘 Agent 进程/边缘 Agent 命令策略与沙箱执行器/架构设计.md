模块按职责拆分为四层：
- types.go 定义核心数据结构（BinaryClass、ArgMatcher、BinaryPolicy、Policy、Decision），确立「类 + 匹配器」的策略模型。
- parse.go 负责将原始 shell 字符串切分为仅允许 `|` 连接的 argv 段，拒绝重定向、反引号、$() 等元字符，确保 exec.Command 始终拿到干净的参数数组。
- policy.go 维护默认只读基线 DefaultReadOnly()（read-fs / read-system / mixed / network / denied 五类二进制）并通过 LoadFromYAML 叠加 /etc/ongrid-edge/bash-policy.yaml 覆盖；Decide 仅做策略判定，不依赖外部 IO。
- sandbox.go 在 Decide 之上叠加 PathValidator（复用 host_files.SandboxConfig）、NetworkHostAllowlist 校验，并实现 Exec/ExecRaw 两个入口：前者通过 runPipeline 以 Linux 风格管道连接子进程、限制输出大小、设置超时与进程组；后者绕过所有策略直接 `/bin/sh -c` 执行，作为管理员写门限的 escape hatch。
依赖方向单向：sandbox → policy → parse/types；policy 对 Sandbox 无感知，可被 dry-run UI 单独复用。
