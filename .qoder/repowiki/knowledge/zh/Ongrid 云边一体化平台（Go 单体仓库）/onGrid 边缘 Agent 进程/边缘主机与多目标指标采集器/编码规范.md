- 所有 Collector 实现都同时实现 CollectAll、HostInfo、GetHostLoad、GetProcessList 四个方法，以被 CompositeCollector 透明替换。
- 指标名称严格遵循 node_exporter 约定（如 node_cpu_seconds_total、node_memory_MemTotal_bytes），使 Embedded 与 Scrape 两条路径共享同一 Mapper。
- 对缺失或首次采样的计数器采用“先缓存后差分”策略：Mapper 内部以 metric_name+排序 label 串为 key 缓存上次读数，首次调用返回 0 避免负增量。
- 错误处理采用“部分失败不阻断”模式：snapshot/scrapeOnce 中单个资源或目标出错仅记录 warn 日志并跳过该片段，继续收集其余数据。
- Source 标识采用前缀约定：embedded 固定为 "embedded"，scrape 目标为 "scrape:<target_name>"，由类型常量集中声明。
