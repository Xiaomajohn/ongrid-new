- 插件名称采用 OpenTelemetry 信号复数形式（metrics/logs/traces/profiles），既作为 `Plugin.Name()` 返回值也作为 `PluginConfig` map 键与环境变量前缀。
- 所有对外可替换组件（配置源、日志器）通过构造函数选项注入（`SupervisorOpts`、`SubprocessOpts`），并提供 nil 默认值（`slog.Default()`、60s reload interval）。
- 配置变更检测走语义相等而非指针比较：`configEqual` 逐项比对 Enabled/EdgeID/Endpoint/AuthUser/AuthPass/Spec，Spec 用 `fmt.Sprintf("%v")` 做浅层对比，避免不必要的重启。
- 错误处理遵循“单插件失败不拖累整体”原则：`reconcile` 中对单个插件的 Configure/Start/Stop 错误仅打 warn 日志并 continue，不会中断对其他插件的处理。
- 子进程退出一律走 SIGTERM + `WaitDelay=10s` 回退 SIGKILL，并通过 `exec.ExitError` 区分正常退出码与非 IO 错误，以便区分“被我们杀死”和“自身崩溃”。
