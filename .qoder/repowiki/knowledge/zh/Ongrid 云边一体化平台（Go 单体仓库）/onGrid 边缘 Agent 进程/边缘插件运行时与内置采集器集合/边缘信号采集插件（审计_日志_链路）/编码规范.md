- 每个插件以 `const Name = "<signal>"` 声明标识符，同时作为 `<workDir>/plugins/<Name>` 下的目录键，供 logs 与测试统一引用。
- `New` 构造器固定返回 `plugins.NewSubprocess(plugins.SubprocessOpts{Name, Binary, WorkDir, ConfigFile, ConfigRender, Args, Log})`，仅差异化二进制名与工作目录。
- `render(cfg, pluginDir)` 首行校验 `cfg.Endpoint == ""` 与 `cfg.EdgeID == 0` 并返回带前缀的错误消息（如 `"logs plugin: endpoint required"`），再进入模板渲染。
- 从 `cfg.Spec map[string]interface{}` 读取字段时使用本地 helper（`stringFieldOr`/`stringSliceField`/`boolFieldStr`/`stringMap`）容忍 JSON 解码出的 `[]interface{}` / `map[string]interface{}` 形状，避免断言 panic。
- 模板字符串以 `# Rendered by ongrid-edge <plugin> plugin.` 注释开头，禁止人工编辑，并通过 `template.FuncMap` 注入 `hasModule`、`jobNameSafe`、`eq` 等窄接口函数控制渲染分支。
- 路径拼接统一使用 `path.Join`（跨平台可编译）或 `filepath.Join`（仅在需要 OS 语义时），并在注释中说明选择原因以保持 audit ↔ logs 间的路径契约稳定。
