本模块由三个并列的子包 `audit`、`logs`、`traces` 组成，每个子包遵循相同的两文件结构：
- `plugin.go`：定义 `Name` 常量与 `New(binDir, workDir, log)` 构造器，通过上层 `plugins.NewSubprocess(plugins.SubprocessOpts{...})` 注册为 `plugins.Plugin`，指定被管二进制名、工作目录、配置路径、`ConfigRender` 回调和命令行参数。
- `render.go`：用 Go `text/template` 把 `plugins.PluginConfig` 渲染成目标二进制的 YAML 配置，并在 `render()` 入口校验 `Endpoint` / `EdgeID` 等必填字段。

依赖方向：`logs` 单向依赖 `audit`（在 render 时调用 `audit.OutputPath(workDir)` 探测并自动追加 `audit.jsonl` 到 Promtail scrape 列表），`audit` 与 `traces` 互不引用；三者共同依赖父包 `internal/edgeagent/plugins` 提供的 `PluginConfig`、`SubprocessPlugin` 生命周期抽象。`audit` 额外暴露 `OutputPath(workDir)` 作为跨包的稳定契约，约定 JSONL 输出位于 `<workDir>/audit/audit.jsonl`，使用 `path.Join`（而非 `filepath.Join`）保证跨 OS 编译时的路径分隔符一致性。所有插件均运行在 systemd `ProtectSystem=strict` + `ReadWritePaths=${STATE_DIR}` 沙箱内，因此 `audit` 显式把 `path.home/data/logs` 钉死到 plugin work dir 以避免 EROFS 崩溃。
